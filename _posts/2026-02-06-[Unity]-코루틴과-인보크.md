## 코루틴 (Coroutine) & 인보크 (Invoke)

### **1. 코루틴 (Coroutine)**
**코루틴**은 코드 안에서 시간의 흐름을 직접 제어하고 싶을 때 사용한다.

#### **코루틴 특징**
- 함수 실행을 중간에 잠시 멈췄다가 다시 이어서 실행한다.
- ```yield return``` 대기 조건을 직접 설정한다.
- 조건에 따라 여러 번 멈추거나 반복하는 **흐름 제어**에 적합하다.

#### **코루틴 예시**
```csharp
// 코루틴 선언
IEnumerator Example()
{
    Debug.Log("시작");
    yield return new WaitForSeconds(2f);
    Debug.Log("2초 후");
}

// 코루틴 호출
StartCoroutine(Example());
```

#### **yield return 예시**
```csharp
yield return new WaitForSeconds(1f);   // 1초 대기
yield return null;                     // 다음 프레임까지 대기
yield return new WaitUntil(() => hp <= 0);		// hp가 0이 될 때까지 대기
yield return new WaitWhile(() => isMoving);		// 움직이는 동안 대기
```

### **2. 인보크 (Invoke)**
**인보크**는 일정 시간 이후 함수를 실행하고 싶을 때 사용한다.

#### **인보크의 특징**
- **문자열** 기반으로 함수를 실행한다.
- 매개변수를 전달할 수 없고 반환값이 없는 함수만 실행 가능하다.
- **단순한 지연**이나 반복 실행에 적합하다.

####  **예시**
```csharp
// 2초 후 DoSomething() 함수 실행
Invoke("DoSomething", 2f);	// 문자열 기반

// 실행할 함수
void DoSomething()
{
    Debug.Log("2초 뒤 실행");
}

// 1초 후 0.5초 간격으로 반복 실행
InvokeRepeating("Tick", 1f, 0.5f);

// 실행 취소
CancelInvoke("DoSomething");
CancelInvoke(); // 전부 취소
```
