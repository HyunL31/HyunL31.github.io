### **1. Static 함수**
- 클래스에 속하며 객체 없이 호출 가능한 함수
- 캡슐화와 이름 충돌 방지가 가능하다.

```csharp
static void method() {}
```

```csharp
using System;

namespace OZCodingCsharp
{
    internal class Program      // 접근 제한자
    {
        static int _globalCoffeePrice;

        static void Main(string[] args)
        {
            int coffeePrice = 0;

            Console.WriteLine(coffeePrice);     // 지역변수는 초기화한 뒤 사용해야 한다.
            Console.WriteLine(_globalCoffeePrice);      // 멤버 변수는 괜찮다.

            float naftaWeight = 5.5f;
            Console.WriteLine(naftaWeight);
        }
    }
}

```

- String: 힙 메모리에 저장

### **3. C#의 String**
- 문자열 연산이 많을 경우 GC 부담이 커진다.
- C++에서 string은 기본으로 제공되는 자료형이 아니었지만 C#에서는 기본 자료형으로 취급된다.
- C#에서 String은 참조 타입이다.
- String은 불변 객체이기에 문자 추가나 수정 시 새로운 객체를 하나 더 만든다.
	- 따라서 메모리 사용량이 증가하기 때문에 while(), Update()에서는 사용하지 않는 것이 좋다.
	- 정 써야할 경우 3초에 한 번 등 타이머를 사용한다.

```csharp
// 문자열 format
string characterLevel = 10;
string result = $"Level {characterLevel}입니다.";

Console.WriteLine(result);
```

### **3. C#의 StringBuilder**
- 문자열의 성능을 높이기 위해 사용한다.
- 문자열 수정 시 내부적으로 새 객체를 만드는 것이 아니라 ToString()으로 문자열화만 한다.
- C#에서의 모든 객체는 ToString()이 가능하다.
- StringBuilder는 성능은 좋지만 코드가 복잡해져 최적화가 필요한 부분 외에는 잘 사용하지 않는다.

```csharp
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World");

string result = sb.ToString();
Console.WriteLine(result);
```

### **4. 그 외 기본 자료형 & 연산자**
- **unsigned** : 부호를 붙일 수 없는 자료형이다. 따라서 음수를 표현할 수 없다.
	- `uint` 등 자료형 앞에 `u`를 붙여서 사용할 수도 있다.
- **byte** : enum 최적화 등을 위해 byte 자료형을 사용한다. (255개 이하일 경우)

- 나눗셈 연산자보다 곱셈 연산자가 더 빠르다. (`a / 2` 대신 `a * 0.5` 사용)

### **5. 형 변환**
```csharp
float characterHP = 95.7f;
int displayHP = (int)characterHP;

Console.WriteLine(displayHP);	// 95 출력

int a = 100;
int b = 200;
float result1 = a / b;		// (정수 / 정수)는 0이 된다.
float result2 = (float)a / b;		// 두 변수 중 하나를 형 변환 시켜줘야 한다.
float result3 = (float)(a / b);	// 연산의 결과 0을 float으로 형 변환했기에 0이 그대로 나옴
```

- 기본 자료형(값 타입)끼리의 형 변환은 비용이 비교적 크지 않아 괜찮다.
- 다만 참조 타입끼리의 형 변환은 주의가 필요하다. (`박싱`, `언박싱`)

```cpp
using System;

namespace DailyAssignmentCSharp
{
    internal class Calculator
    {
        static int Plus(int first, int second)
        {
            int plusResult = first + second;

            return plusResult;
        }

        static int Minus(int first, int second)
        {
            int minusResult = first - second;

            return minusResult;
        }

        static int Multiply(int first, int second)
        {
            int multipliedResult = first * second;

            return multipliedResult;
        }

        static int Divide(int first, int second)
        {
            int divideResult = 0;

            try
            {
                divideResult = first / second;
            }
            catch (DivideByZeroException ex)
            {
                Console.WriteLine("0으로 나눌 수 없습니다.");
            }

            return divideResult;
        }

        static int Mod(int first, int second)
        {
            int modResult = 0;

            try
            {
                modResult = first % second;
            }
            catch (DivideByZeroException ex)
            {
                Console.WriteLine("0으로 나눌 수 없습니다.");
            }

            return modResult;
        }

        static int Square(int first, int second)
        {
            int squareResult = 1;

            for (int i = 0; i < second; i++)
            {
                squareResult *= first;
            }

            return squareResult;
        }

        static void Everything(int first, int second)
        {
            Console.WriteLine($"{first} + {second} = {Plus(first, second)}");
            Console.WriteLine($"{first} - {second} = {Minus(first, second)}");
            Console.WriteLine($"{first} * {second} = {Multiply(first, second)}");
            Console.WriteLine($"{first} / {second} = {Divide(first, second)}");
            Console.WriteLine($"{first} % {second} = {Mod(first, second)}");
            Console.WriteLine($"{first} ^ {second} = {Square(first, second)}");
        }

        static void Main(string[] args)
        {
            Console.WriteLine("두 수를 입력받아 계산하는 \"계산기\"입니다.\n");

            Console.WriteLine("원하는 연산의 숫자 중 하나를 골라 입력해주세요.");
            Console.WriteLine("1. +\n2. -\n3. *\n4. /\n5.%\n6. 제곱\n7. 위의 모든 연산\n");
            int expression = int.Parse(Console.ReadLine());

            Console.WriteLine("연산할 두 수를 하나씩 입력해주세요.");
            
            Console.Write("첫 번째 수: ");
            int firstNum = int.Parse(Console.ReadLine());

            Console.WriteLine();

            Console.Write("두 번째 수: ");
            int secondNum = int.Parse(Console.ReadLine());

            Console.WriteLine("연산 결과를 출력합니다.\n");

            switch (expression)
            {
                case 1:
                    Console.WriteLine($"{firstNum} + {secondNum} = {Plus(firstNum, secondNum)}");
                    break;

                case 2:
                    Console.WriteLine($"{firstNum} - {secondNum} = {Minus(firstNum, secondNum)}");
                    break;

                case 3:
                    Console.WriteLine($"{firstNum} * {secondNum} = {Multiply(firstNum, secondNum)}");
                    break;

                case 4:;
                    Console.WriteLine($"{firstNum} / {secondNum} = {Divide(firstNum, secondNum)}");
                    break;

                case 5:
                    Console.WriteLine($"{firstNum} % {secondNum} = {Mod(firstNum, secondNum)}");
                    break;

                case 6:
                    Console.WriteLine($"{firstNum} ^ {secondNum} = {Square(firstNum, secondNum)}");
                    break;

                case 7:
                    Everything(firstNum, secondNum);
                    break;
            }

            Console.ReadLine();
        }
    }
}
```

### **1. .Net 프레임워크 (닷넷)**
- C#은 코드가 바로 기계어가 되는 것이 아니라 IL(중간 언어)로 변환된 후 **가상 머신 (CLR)**이 **실시간**으로 번역한다.
- 이렇게 실시간으로 기계어로 번역해주는 가상머신을 포함한 것이 **닷넷 프레임워크**이다.

<br/>

-----------------

<br/>

### **2. namespace**
- **네임스페이스**란 클래스, 함수 등을 그룹으로 묶는 것으로 동일한 이름 충돌을 방지하기 위해 사용한다.
- C#에서는 C++에서 헤더파일을 사용하는 것처럼 네임스페이스를 사용해 다양한 함수 등을 가져올 수 있다.
- C++의 #include는 헤더파일을 복사하여 포함시키는 방식이다.
- C#의 using은 네임스페이스를 참조하는 방식이다.

<br/>

-----------------

<br/>

### **3. 값 타입 & 참조 타입**
- **값 타입** : 변수에 실제 값이 저장되며 선언 위치에 따라 스택 또는 힙에 저장된다.
	- C#에서 값 타입을 참조로 전달할 경우 `&` 대신 `ref` 키워드를 사용한다.
	- `out` 키워드를 사용할 경우 함수 내에 대입 연산이 있어야 한다.
- **참조 타입** : 변수에는 주소가 저장되고 실제 객체는 힙에 생성된다.

<br/>

-----------------

<br/>

### **4. readonly**
- **readonly**는 값을 한 번만 설정하고 이후에는 변경할 수 없게 만드는 상수화 키워드이다.
- 초기화는 가능하지만 이후 수정은 불가능하다. (생성자에서 초기화 가능)
- **const**처럼 멤버 변수에서만 사용 가능하다.
- **const**와 달리 초기값이 **런타임**에 설정된다.

```csharp
using System;

namespace DailyAssignmentCSharp
{
    enum Environment
    {
        Sunlight,
        Water,
        Darkness,
        Nutrients
    }

    enum State
    {
        Seed,
        Sprout,
        Flower,
        Die,
        Dead
    }

    class Plant
    {
        private string _plantName;
        private Environment _environment;
        private State _plantState = State.Seed;
        private int _hp = 50;
        private int waterCount = 0;

        public Plant(string name, Environment environment)
        {
            this._plantName = name;
            this._environment = environment;
        }

        public string GetPlantName()
        {
            return this._plantName;
        }

        public void SetState(State state)
        {
            this._plantState = state;
        }

        public State GetState()
        {
            return this._plantState;
        }

        public int GetWaterCount()
        {
            return waterCount;
        }

        public Environment GetEnvironment()
        {
            return this._environment;
        }

        public void Watering()
        {
            this.waterCount++;
        }

        public void PrintState(Owner player)
        {
            if (this._plantState == State.Seed)
            {
                Console.WriteLine("아직 씨앗 상태입니다.\n물을 주세요.\n");
            }
            else if (this._plantState == State.Sprout)
            {
                Console.WriteLine($"{this._plantName} 이(가) 점점 자라고 있습니다.\n");
            }
            else if (this._plantState == State.Flower)
            {
                Console.WriteLine("꽃이 피어났습니다!\n");
                player.Win(this);
            }
            else if (this._plantState == State.Die)
            {
                Console.WriteLine($"{this._plantName} 이(가) 죽어가고 있습니다...\n긍정적인 감정이 필요합니다...\n");
            }
            else
            {
                Console.WriteLine($"{this._plantName} 이(가) 시들었습니다...\n");
                player.Lose(this);
            }
        }
    }

    class Owner
    {
        private string _ownerName;
        private int _sad = 0;
        private int _angry = 0;
        private int _calm = 0;
        private int _happy = 0;

        public Owner(string ownerName)
        {
            this._ownerName = ownerName;
        }

        public int GetSad()
        {
            return this._sad;
        }

        public int GetAngry()
        {
            return this._angry;
        }

        public int GetCalm()
        {
            return this._calm;
        }

        public int GetHappy()
        {
            return this._happy;
        }

        public string GetName()
        {
            return this._ownerName;
        }

        public void CalculateEmotion(int userToday)
        {
            if (userToday == 1)
            {
                this._sad += 10;
            }
            else if (userToday == 2)
            {
                this._angry += 10;
            }
            else if (userToday == 3)
            {
                this._calm += 10;
            }
            else if (userToday == 4)
            {
                this._happy += 10;
            }
        }

        public void WaterPlant(Plant plant)
        {
            plant.Watering();
        }

        public void Win(Plant plant)
        {
            Console.WriteLine($"성공적으로 {plant.GetPlantName()}을(를) 키웠습니다.\n축하드립니다!!");
        }

        public void Lose(Plant plant)
        {
            Console.WriteLine($"안타깝게 {plant.GetPlantName()}은(는) 시들었습니다...\n다시 시작해주세요...");
        }

        public void Normal(Plant plant)
        {
            Console.WriteLine($"꽃을 피우지는 못했지만 {plant.GetPlantName()}은(는) 건강합니다. 다시 시작해주세요.");
        }
    }

    internal class GrowPlant
    {
        static void Main(string[] args)
        {
            Console.WriteLine("당신의 이름은 무엇인가요?");
            Console.Write("이름: ");
            string ownerName = Console.ReadLine();

            Owner player = new Owner(ownerName);

            Console.WriteLine("키울 식물의 이름은 무엇인가요?");
            Console.Write("식물 이름: ");
            string plantName = Console.ReadLine();

            Console.WriteLine("현재의 감정은 어떤신가요?");
            Console.WriteLine("1. 슬픔\n2. 화남\n3. 차분함\n4. 행복함");

            int userEmotion = int.Parse(Console.ReadLine());

            Environment environment = Environment.Sunlight;

            if (userEmotion == 1)
            {
                environment = Environment.Water;
            }
            else if (userEmotion == 2)
            {
                environment = Environment.Darkness;
            }
            else if (userEmotion == 3)
            {
                environment = Environment.Sunlight;
            }
            else if (userEmotion == 4)
            {
                environment = Environment.Nutrients;
            }

            Plant plant = new Plant(plantName, environment);

            Console.WriteLine($"오늘부터 7일동안 {plant.GetPlantName()}을(를) 키우게 됩니다.\n무럭무럭 자라도록 잘 키워봅시다!");

            for (int i = 0; i < 7; i++)
            {
                Console.WriteLine($"\nDay {i + 1}");
                plant.PrintState(player);

                if (plant.GetState() == State.Flower || plant.GetState() == State.Dead)
                {
                    break;
                }

                Console.WriteLine("1을 눌러 물을 주세요.");
                int userInput = int.Parse(Console.ReadLine());

                if (userInput == 1)
                {
                    player.WaterPlant(plant);
                }

                if ((i + 1) - plant.GetWaterCount() >= 5)
                {
                    plant.SetState(State.Dead);
                    break;
                }
                else if ((i + 1) - plant.GetWaterCount() >= 3)
                {
                    plant.SetState(State.Die);
                }

                Console.WriteLine("오늘의 감정은 어떠신가요?");
                Console.WriteLine("1. 슬픔\n2. 화남\n3. 차분함\n4. 행복함");
                int userToday = int.Parse(Console.ReadLine());

                player.CalculateEmotion(userToday);

                if (player.GetSad() >= 30 || player.GetAngry() >= 30)
                {
                    plant.SetState(State.Dead);
                    break;
                }

                if (plant.GetWaterCount() >= 6)
                {
                    plant.SetState(State.Flower);
                }
                else if (plant.GetWaterCount() >= 3)
                {
                    plant.SetState(State.Sprout);
                }
                else
                {
                    plant.SetState(State.Seed);
                }
            }

            if (plant.GetState() == State.Flower)
            {
                player.Win(plant);
            }
            else if (plant.GetState() == State.Dead)
            {
                player.Lose(plant);
            }
            else
            {
                player.Normal(plant);
            }

            Console.ReadLine();
        }
    }
}
```

```csharp
using System;
```

### **1. var 타입**
- **var 타입**: 자료형을 알아서 자동으로 결정해주는 자료형이다.
- 편리하지만 가독성이나 유지 보수 등에서 문제가 될 수 있기에 기본 자료형에서는 잘 쓰지 않는다.
- 동적 할당처럼 뒤에 명시적으로 자료형이 나와있는 경우에 주로 사용한다.
- 컴파일 타입에 자료형이 결정된다.

#### **예시**
```csharp
// 기본 자료형에서는 굳이 var 타입을 사용하지 않는다.
// 오히려 가독성과 유지보수성을 해친다.
var name = "몬스터";
var age = 24;
var isAlive = false;

// 뒤에 타입이 명확하니 var 타입을 사용해도 된다.
var monster = new Monster();
```

### **2. 클래스 & 구조체**
- **C++**에서의 클래스와 구조체는 큰 차이가 없다.
- **C#**에서는 클래스와 구조체가 아예 다르다.
	- **구조체 (Structure)** : 값 타입으로 **스택 메모리**에 저장되고 **값 복사**가 일어난다.
	- **클래스 (Class)** : 참조 타입으로 **힙 메모리**에 저장되고 **참조 전달**이 일어난다.
	- 클래스 뿐만 아니라 구조체를 사용할 때도 new 키워드를 사용하지만 여전히 구조체는 스택 메모리에 저장된다.
	- 다만 delete 키워드로 소멸자를 불러오지 않고 가비지 콜렉터를 이용한다는 점이 C++과 다르다.

### **3. 값 타입 & 참조 타입**
- **값 타입** : **스택 메모리**에 저장되고 **값 복사**가 일어난다.
	- 값의 원본이 바로 바뀌는 것이 아니라 똑같은 값의 변수가 복사되어 전달된다.
	- 스코프 범위를 넘어가면 자동으로 메모리에서 사라진다.

<br/>

- **참조 타입** : **힙 메모리**에 저장되고 **참조 전달**이 일어난다.
	- 변수 원본의 주소가 전달되어 원본이 바로 바뀐다.
	- 참조가 끊기면 GC가 나중에 처리한다.
	- `string`은 참조 타입!!

### **4. 상속**
- C#에서 다중 상속은 불가능하다. 그래서 인터페이스를 사용하기도 한다.
	- **인터페이스**는 데이터가 없고 기능만 있다.
	- 클래스처럼 인터페이스를 상속받아 그 기능을 사용할 수 있다. 
-  오버라이딩 할 때 base 키워드를 사용하면 부모 클래스의 함수를 사용할 수 있다.

```csharp
public class Parent

	{
		Console.WriteLine($"{this._name}입니다.");
	}
}

public class Child : Parent
{
	private string _extraName;

	public override void SpeakName()
	{
		base.SpeakName();
		Console.WriteLine($"별명은 {this._extraName}입니다.");
	}
```

### **3. null**

### **1. Static**
- **static** : 프로그램에서 **딱 1개**만 생성된다.
	- 유니티 에디터에서 static을 사용하면 에디터가 종료될 때까지 남아있다.
	- 싱글톤 패턴 등에서 사용된다.
- **static 멤버 변수** : 클래스 내의 static 변수는 위험하다.
	- 전역 변수처럼 사용하는 경우가 많다. (매니저 클래스로 뺄 수도 있다.)
	- C#의 데이터 영역은 힙 영역이지만 GC가 돌지 않는 공간을 의미한다.
- 클래스 안이든 밖이든 코드 영역에 딱 1개만 전달된다.
- 다만 static은 this가 전달되지 않는 함수에 붙는다. (유틸 함수 등)
	- 별도의 객체 생성 없이 함수를 사용할 수 있다.

### **5. 데일리 과제**
- **리스트 (List)** : 리스트는 선형 자료구조로 배열처럼 같은 자료형의 데이터를 순차적으로 저장하는 자료구조이다.
	- 배열과 달리 크기를 유동적으로 바꿀 수 있다.
	- `몬스터 리스트`, `아이템 인벤토리`, `덱 / 카드 시스템`, `친구 목록 / 랭킹 UI` 등에 사용된다.


```csharp
List<int> list = new List<int>();

for (int i = 0; i < 10; i++)
{
	list.Add(i + 1);
}

for (int i = 0; i < 10; i++)
{
	Console.WriteLine(list[i]);		// 1 ~ 10 출력
}
```

<br/>

- **연결리스트 (LinkedList)** : 연결리스트는 리스트와 비슷하지만 노드로 연결된 리스트이다.
	- 노드끼리의 연결만 바꿔주면 되기 때문에 데이터의 추가와 삭제가 빠르다.
	- 다만 순차적으로 접근하기 때문에 검색이 잦은 경우에는 그냥 리스트가 더 빠르다.
	- 주로 `객체 풀링`, `동적 관리` 등에서 사용되지만 보통은 그냥 리스트를 더 많이 사용한다.


```csharp
LinkedList<int> llist = new LinkedList<int>();

llist.AddLast(1);
llist.AddLast(2);
llist.AddFirst(3);		// 3 - 1 - 2 순으로 저장
```

<br/>

- **딕셔너리 (Dictionary)** : 딕셔너리는 키와 값을 쌍으로 저장할 수 있는 자료구조이다.
	- 데이터가 키와 값이 함께 저장되어 키를 통해 값을 쉽고 빠르게 불러올 수 있다.
	- 주로 `상태 / 설정 관리`, `객체 ID 관리`, `리소스 관리` 등에 사용된다.


```csharp
Dictionary<int, string> dict = new Dictionary<int, string>();

dict[1] = "멍멍이";
dict[2] = "야옹이";
dict[3] = "쮝쮝이";

Console.WriteLine(dict[1]);		// "멍멍이" 출력
``` 

<br/>

- **스택 (Stack)** : 스택은 **후입선출 (Last In First Out, LIFO)** 형태의 자료구조이다.
	- 가장 나중에 들어간 데이터가 가장 빨리 나온다.
	- 주로 `씬 / 상태 저장`, `플레이어 행동 기록`, `UI 뒤로가기` 등에 사용된다.


```csharp
Stack<int> st = new Stack<int>();

for (int i = 0; i < 10; i++)
{
	st.Push(i + 1);		// 1 ~ 10까지 순서대로 들어간다.
}

for (int i = 0; i < 10; i++)
{
	st.Pop();		// 10 ~ 1까지 반대로 나온다.
}
``` 

<br/>

- **큐 (Queue)** : 큐는 **선입선출 (First In First Out, FIFO)** 형태의 자료구조이다.
	- 스택과 반대로 먼저 들어간 데이터가 가장 먼저 나온다.
	- 주로 `대기열 처리`, `서버 요청 처리`, `대사 출력`, `공격 / 이벤트 처리`, `애니메이션 / 이펙트 처리` 등에 사용된다.


```csharp
Queue<int> que = new Queue<int>();

for (int i = 0; i < 10; i++)
{
	que.Enqueue(i + 1); 		// 1 ~ 10까지 순서대로 들어간다. 
}

for (int i = 0; i < 10; i++)
{
	que.Dequeue();		// 1 ~ 10까지 순서대로 나온다.
}
```

<br/>

- **집합 (HashSet)** : 집합이란 중복되지 않는 데이터들을 저장하는 자료구조이다.
	- 이미 집합 내에 있는 데이터가 다시 들어올 경우 자동으로 제거된다.
	- 주로 `아이템, 칭호 등 중복 방지`, `방문 체크`, `존재 확인`, `버프 관리` 등에 사용된다.


```csharp
HashSet<string> hs = new HashSet<string>();

hs.Add("전사 칭호");
hs.Add("힐러 칭호");
hs.Add("전사 칭호");		// 자동으로 무시된다.

foreach(string str in hs)
{
	Console.WriteLine(str);		// "전사 칭호", "힐러 칭호" 출력
}
```

<br/>

- **SortedList / SortedDictionary** : 리스트와 딕셔너리이지만 데이터를 자동으로 정렬해주는 자료구조이다.

<br/>

- **제네릭 (Generic)** : 타입을 컴파일 타임에 미리 받아 형 변환이 필요 없어 안전하다. (위의 자료구조들)
- **논제네릭 (Non-Generic)** : 제네릭과 반대로  모든 타입을 object로 받기 때문에 형 변환이 필요하고 런타임에 오류를 검사한다.
	- `ArrayList`, `HashTable` 등이 논제네릭 자료구조이다.
	- 사실상 잘 사용하지 않는 형태의 자료구조이다.
	- 논제네릭은 박싱과 언박싱이 발생한다.

### **2. 정렬 알고리즘**
- **삽입 정렬** : 앞의 데이터와 비교해 적은 값을 찾아낼 때까지 뒤로 밀어낸다. 두 번째 데이터부터 시작한다.
- **버블 정렬** : 인접 데이터와 비교하며 정렬한다. 맨 뒤에서부터 정렬이 된다.
- **선택 정렬** : 최소값이 찾아 순차적으로 정렬한다.
- **퀵 정렬** : 기준점을 잡고 작으면 왼쪽, 크면 오른쪽으로 보내는 것을 반복한다.
- **병합 정렬** : 리스트를 절반으로 자르는 것을 반복하고 정렬하며 합치는 것을 반복한다. (재귀)

```csharp
// 삽입 정렬
static void InsertionSort(int[] arr)
{
	for (int i = 1; i < arr.Length; i++)
	{
		int key = arr[i];
		int j = i - 1;

		while (j >= 0 && arr[j] > key)
		{
			arr[j + 1] = arr[j];
			j--;
		}

		arr[j + 1] = key;
	}
}

// 버블 정렬
static void BubbleSort(int[] arr)
{
	for (int i = 0; i < arr.Length - 1; i++)
	{
		for (int j = 0; j < arr.Length - 1 - i; j++)
		{
			if (arr[j] > arr[j + 1])
			{
				int temp = arr[j];
				arr[j] = arr[j + 1];
				arr[j + 1] = temp;
			}
		}
	}
}

// 선택 정렬
static void SelectionSort(int[] arr)
{
		for (int i = 0; i < arr.Length - 1; i++)
		{
			int minIdx = i;

			for (int j = i + 1; j < arr.Length; j++)
			{
				if (arr[j] < arr[minIdx])
				{
					minIdx = j;
				}
			}

			int temp = arr[i];
			arr[i] = arr[minIdx];
			arr[minIdx] = temp;
	}
}

// 퀵 정렬
static void QuickSort(int[] arr, int left, int right)
{
	if (left < right)
	{
		int pivot = Partition(arr, left, right);

		QuickSort(arr, left, pivot - 1);
		QuickSort(arr, pivot + 1, right);
	}
}

static int Partition(int[] arr, int left, int right)
{
	int pivot = arr[right];
	int idx = left - 1;

	for (int i = left; i < right; i++)
	{
		if (arr[i] < pivot)
		{
			idx++;

			int temp1 = arr[idx];
			arr[idx] = arr[i];
			arr[i] = temp1;
		}
	}

	int temp2 = arr[idx + 1];
	arr[idx + 1] = arr[right];
	arr[right] = temp2;

	return idx + 1;
}

// 병합 정렬
static void MergeSort(int[] arr, int left, int right)
{
	if (left < right)
	{
		int mid = (left + right) / 2;

		MergeSort(arr, left, mid - 1);
		MergeSort(arr, mid + 1, right);

		Merge(arr, left, mid, right);
	}
}

static void Merge(int[] arr, int left, int mid, int right)
{
	int[] temp = new int[right -  left + 1];
	
	int i = left;
	int j = mid + 1;
	int k = 0;

	while (i <= mid && j <= right)
	{
		 if (arr[i] <= arr[j])
		{
			temp[k++] = arr[i++];
		}
		else
		{
			temp[k++] = arr[j++];
		}
	}

	while (i <= mid)
	{
		temp[k++] = arr[i++];
	}

	while (j <= right)
	{
		temp[k++] = arr[j++];
	}

	for (int idx = 0; idx < temp.Length; idx++)
	{
		arr[left + idx] = temp[idx];
	}
}
```

### **1. 프로퍼티 (속성)**
- **프로퍼티** : 멤버 변수에 안전하게 접근할 수 있게 하기 위해 만든 메서드를 의미한다.
- **Get**, **Set** 키워드가 사용된다.
- 이런 Getter, Setter를 통해 Private으로 선언된 멤버 변수에 접근할 수 있다.
- 프로퍼티는 **캡슐화**, **정보은닉**에 중요한 요소이다.
- 단순히 GetMoney() 등의 메서드를 만들면 클래스가 너무 복잡해지기 때문에 프로퍼티를 사용한다.

```csharp
// 일반 Get, Set 함수
int GetGold()
{
	return this._gold;
}

void SetGold(int newGold)
{
	this._gold = newGold;
}

// 프로퍼티 Get, Set
private int _gold;

public int Gold(int newGold)
{
	Get{ return this._gold; }
	Set
	{
		this._gold = newGold;
	}
} 

// 사용 (명사, 멤버변수처럼 접근)
entity.Gold = 100;

// 간단한 과정
public int _gold {get; private set;}
```

### **5. 평과 과제**
```csharp
using System;
using System.Collections.Generic;

namespace DailyAssignmentCSharp
{
    internal class Bakery
    {
        public interface IMakeAndSell
        {
            void Make();
            void Sell();
        }

        public class Player
        {
            public string Name { get; set; }
            public string StoreName { get; set; }
            public int Gold { get; set; }
            public int Bread {  get; set; }
            public int Drink { get; set; }

            public void PlayerInit(int gold, int bread, int drink)
            {
                Gold = gold;
                Bread = bread;
                Drink = drink;
            }
        }

        public class Food
        {
            public string Name { get; set; }
            public int Price { get; set; }
            public int Count { get; set; }

            public Food(string name, int count)
            {
                Name = name;
                Count = count;
            }

            public virtual void PrintFood()
            {
                Console.WriteLine("===============================");
                Console.WriteLine($"- 이름: {this.Name}\n- 가격: {this.Price}\n- 개수: {this.Count}");
            }
        }

        public class Drink : Food, IMakeAndSell
        {
            public Drink(string name, int count, int price) : base(name, count)
            {
                Price = price;
            }

            public override void PrintFood()
            {
                base.PrintFood();
                Console.WriteLine($"- 종류: 음료");
                Console.WriteLine("===============================");
            }

            public void Make()
            {
                Console.WriteLine($"음료 {this.Name}을(를) 만들었습니다.");
                this.Count++;

                Console.WriteLine("100원을 지불했습니다.");
            }

            public void Sell()
            {
                Console.WriteLine($"음료 {this.Name}을(를) 팔았습니다.");
                this.Count--;

                Console.WriteLine($"{this.Price}원을 얻었습니다.");
            }
        }

        public class Bread : Food, IMakeAndSell
        {
            public Bread(string name, int count, int price) : base(name, count)
            {
                Price = price;
            }

            public override void PrintFood()
            {
                base.PrintFood();
                Console.WriteLine($"- 종류: 빵");
                Console.WriteLine("===============================");
            }

            public void Make()
            {
                Console.WriteLine($"빵 {this.Name}을(를) 만들었습니다.");
                this.Count++;

                Console.WriteLine("100원을 지불했습니다.");
            }

            public void Sell()
            {
                Console.WriteLine($"빵 {this.Name}을(를) 팔았습니다.");
                this.Count--;

                Console.WriteLine($"{this.Price}원을 얻었습니다.");
            }
        }

        static void Main(string[] args)
        {
            Player player = new Player();
            player.PlayerInit(100, 0, 0);

            Console.WriteLine("당신의 이름을 입력해주세요.");
            player.Name = Console.ReadLine();

            Console.WriteLine("오픈할 가게 이름을 입력해주세요.");
            player.StoreName = Console.ReadLine();

            Console.WriteLine($"카페 {player.StoreName}에 오신 것을 환영합니다.");
            Console.WriteLine("다섯 가지 메뉴를 판매할 수 있습니다.");

            Dictionary<string, Food> foods = new Dictionary<string, Food>();

            for (int i = 0; i < 5; i++)
            {
                Console.WriteLine("어떤 메뉴를 판매할까요?");
                Console.WriteLine("1. 음료    2. 빵");
                int userInput = int.Parse(Console.ReadLine());

                if (userInput == 1)
                {
                    player.Drink++;
                    string drinkName;

                    while (true)
                    {
                        Console.WriteLine("음료의 이름을 입력해주세요.");
                        drinkName = Console.ReadLine();

                        if (foods.ContainsKey(drinkName))
                        {
                            Console.WriteLine("이미 있는 이름입니다.");
                            continue;
                        }
                        else
                        {
                            break;
                        }
                    }

                    Drink drink = new Drink(drinkName, 1, 150);
                    foods.Add(drinkName, drink);
                }
                else
                {
                    player.Bread++;
                    string breadName;

                    while (true)
                    {
                        Console.WriteLine("빵의 이름을 입력해주세요.");
                        breadName = Console.ReadLine();

                        if (foods.ContainsKey(breadName))
                        {
                            Console.WriteLine("이미 있는 이름입니다.");
                            continue;
                        }
                        else
                        {
                            break;
                        }
                    }

                    Bread bread = new Bread(breadName, 1, 200);
                    foods.Add(breadName, bread);
                }
            }

            Console.WriteLine($"카페 {player.StoreName}을(를) 오픈했습니다.");
            Console.WriteLine($"자본금이 0원이 되면 폐업합니다.\n자본금이 10000원이 되면 '카페의 신'이 되어 모두의 칭송을 받습니다.");

            while (true)
            {
                Console.WriteLine($"현재 자본금은 {player.Gold}원입니다.");

                if (player.Gold <= 0)
                {
                    Console.WriteLine($"아쉽게도 카페 {player.StoreName}은(는) 폐업을 하고 말았습니다...");
                    return;
                }
                else if (player.Gold > 10000)
                {
                    break;
                }

                Console.WriteLine("무엇을 할까요?");
                Console.WriteLine("1. 메뉴 확인\n2. 빵 만들기\n3. 음료 만들기\n4. 빵 판매하기\n5. 음료 판매하기");
                int userInput = int.Parse(Console.ReadLine());

                if (userInput == 1)
                {
                    foreach (var food in foods)
                    {
                        food.Value.PrintFood();
                    }
                }
                else if (userInput == 2)
                {
                    if (player.Gold <= 100)
                    {
                        Console.WriteLine("빵을 만들기 위해 100원이 필요합니다.\n자본금이 부족합니다.");
                        continue;
                    }
                    else if (player.Bread <= 0)
                    {
                        Console.WriteLine("만들 수 있는 메뉴가 없습니다.");
                        continue;
                    }

                    Console.WriteLine("어떤 빵을 만들까요?\n이름을 입력해주세요.");

                    foreach (var food in foods)
                    {
                        if (food.Value is Bread)
                        {
                            food.Value.PrintFood();
                        }
                    }

                    string breadName = Console.ReadLine();
                    Bread bread = foods[breadName] as Bread;
                    bread.Make();

                    player.Gold -= 100;
                }
                else if (userInput == 3)
                {
                    if (player.Gold <= 100)
                    {
                        Console.WriteLine("음료를 만들기 위해 100원이 필요합니다.\n자본금이 부족합니다.");
                        continue;
                    }
                    else if (player.Drink <= 0)
                    {
                        Console.WriteLine("만들 수 있는 메뉴가 없습니다.");
                        continue;
                    }

                    Console.WriteLine("어떤 음료를 만들까요?\n이름을 입력해주세요.");

                    foreach (var food in foods)
                    {
                        if (food.Value is Drink)
                        {
                            food.Value.PrintFood();
                        }
                    }

                    string drinkName = Console.ReadLine();
                    Drink drink = foods[drinkName] as Drink;
                    drink.Make();

                    player.Gold -= 100;
                }
                else if (userInput == 4)
                {
                    if (player.Bread <= 0)
                    {
                        Console.WriteLine("판매할 수 있는 메뉴가 없습니다.");
                        continue;
                    }

                    Console.WriteLine("어떤 빵을 판매할까요?\n이름을 입력해주세요.");

                    foreach (var food in foods)
                    {
                        if (food.Value is Bread)
                        {
                            food.Value.PrintFood();
                        }
                    }

                    string breadName = Console.ReadLine();

                    if (foods[breadName].Count <= 0)
                    {
                        Console.WriteLine("판매할 수 있는 빵이 없습니다.");
                        continue;
                    }

                    Bread bread = foods[breadName] as Bread;
                    bread.Sell();

                    player.Gold += bread.Price;
                }
                else
                {
                    if (player.Drink <= 0)
                    {
                        Console.WriteLine("판매할 수 있는 메뉴가 없습니다.");
                        continue;
                    }

                    Console.WriteLine("어떤 음료를 판매할까요?\n이름을 입력해주세요.");

                    foreach (var food in foods)
                    {
                        if (food.Value is Drink)
                        {
                            food.Value.PrintFood();
                        }
                    }

                    string drinkName = Console.ReadLine();

                    if (foods[drinkName].Count <= 0)
                    {
                        Console.WriteLine("판매할 수 있는 음료가 없습니다.");
                        continue;
                    }

                    Drink drink = foods[drinkName] as Drink;
                    drink.Sell();

                    player.Gold += drink.Price;
                }
            }

            Console.WriteLine($"축하드립니다.\n'카페의 신'이 되었습니다.\n모두가 {player.Name}을(를) 칭송합니다.");
        }
    }
}
```
