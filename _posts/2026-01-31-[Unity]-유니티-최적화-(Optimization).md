## 유니티 최적화 (Optimization)

### **1. 최적화 (Optimization)**
게임 개발에서 **최적화**란 같은 결과를 더 적은 자원을 사용해 더 안정적이고 빠르게 만들어내는 과정이다.

다음은 최적화와 관련된 용어들이다.

<br/>

-----------------

<br/>

### **2. 프로파일러 (Profiler)**
**유니티 프로파일러**란 게임 실행 중 CPU, GPU, 렌더링, 메모리 등의 각 요소가 시간을 얼마나 사용하는지 실시간으로 측정하고 분석해주는 도구이다.

이 프로파일러를 통해 확인할 수 있는 프레임 드랍, 병목 지점 등을 중심으로 최적화를 진행한다.

<br/>

-----------------

<br/>

### **3. 프레임 드랍 (Frame Drop)**
1초에 그려야하는 프레임 수 (FPS)가 순간적으로 감소하는 것이다.
즉, 제한 시간 안에 그려야 하는 프레임을 다 그리지 못했다는 의미이다.

**프레임 드랍** 발생 시 화면이 끊기거나 캐릭터 입력이 늦는 등 플레이어에게 불편함을 주기에 최대한 피해야 한다.

<br/>

-----------------

<br/>

### **4. 가비지 콜렉션 (Garbage Collection)**
C#에서 메모리를 자동으로 관리해주는 도구이다.
즉, 프로그램에서 더 이상 사용하지 않는 메모리를 찾아 자동으로 회수한다.

이를 통해 사용자는 직접 메모리를 해제할 필요가 없고 메모리 누수를 방지할 수 있다.

하지만 가비지 콜렉션이 실행되는 주기는 예측할 수 없기 때문에
사용자가 직접 메모리를 해제할 때와 달리 해제 시점을 지정하거나 알 수 없다.

또 가비지 콜렉션이 실행되는 동안 메인 스레드가 정지하기 때문에 프레임 드랍이 발생할 수 있다.
따라서 불필요한 메모리 할당을 줄이는 것이 중요하다.

<br/>

-----------------

<br/>

### **5. 드로우 콜 (Draw Call)**
어떤 오브젝트를 렌더링 하기 위해서는 CPU가 GPU에게 ```"이 오브젝트를 어떤 재질, 어떤 상태로 그려"```라는 명령을 전달해야 한다.

**드로우 콜**이란 이때 명령을 GPU에게 전달하는 호출 한 번을 말한다.
즉, CPU에서 GPU로 명령을 한 번 전달할 때마다 드로우 콜이 쌓인다.

따라서 드로우 콜이 너무 많이 쌓일 경우 CPU에 과부하가 걸리고 병목 현상이 발생한다.
