### **3. 아트 리소스 수집**
아트 리소스는 대부분 제미나이와 챗지피티로 만들었다. 고마워 애들아

<br/>

![Desktop View](/assets/img/Art1.jpg){: w="700" h="400" }

처음에 뽑은 게 이 세 가지였는데 화풍을 정확하게 알려주지 않아서 그런지 말을 잘 안 들었다.  
그래도 두 번째 이미지의 캐릭터는 마음에 들어서 이를 기반으로 수채화풍의 캐릭터를 뽑아달라고 요청했다.

<br/>

![Desktop View](/assets/img/Player1.jpg){: w="700" h="400" }

그래서 나온 게 이 캐릭터. 너어어무 마음에 든다. 반묶음 주황머리 완전 내 취향.

<br/>

![Desktop View](/assets/img/Art2.jpg){: w="700" h="400" }

그리고 비슷한 화풍으로 에피소드에 맞는 캐릭터들과 오프닝, 엔딩 배경, 그리고 각종 아이템 리소스들을 뽑았다.  
급하게 약재 수집 콘텐츠에 사용할 주인공의 걷기, 공격, 기절 모션도 만족스럽게 뽑았다.  
다만 간격이 일정하지 않아 나중에 직접 편집을 해야 할 것 같다.  
나머지 몬스터와 사냥 맵은 에셋 스토어의 무료 에셋을 사용할 예정이다.  
(몬스터는 시간이 되면 제미나이로 한 번 뽑아볼까 고민 중...)

### **4. 데이터 테이블 작성**

![Desktop View](/assets/img/Data2.jpg){: w="700" h="400" }

아트 리소스를 뽑은 다음에는 데이터 테이블을 작성했다.  
위의 이미지가 그 구조!  
생각보다 복잡하고 모든 것을 다 데이터 테이블로 작성한 건 아닐지 걱정했지만 나쁘지 않다고 하셔서 다행이다.  

<br/>

![Desktop View](/assets/img/data3.jpg){: w="700" h="400" }

생각보다 시간이 제일 오래 걸렸던 건 시나리오 테이블...  
대사 쓰는 게 너무 힘들었다...  
그래도 시나리오 테이블을 작성하고 나니 다른 테이블들은 어떻게 쓰는지 감이 조금씩 잡히기 시작했다.  
나중에 추가한 사냥 콘텐츠 관련 테이블은 아직 작성하지 않았다.
