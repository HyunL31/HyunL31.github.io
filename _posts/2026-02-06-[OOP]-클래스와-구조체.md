## 클래스 (Class) & 구조체 (Struct)

### **1. 클래스와 구조체**
클래스와 구조체는 모두 **사용자 정의 자료형**이다.
다만 C++과 C#에서 각각 다른 차이점이 있다.

#### **클래스와 구조체의 공통점**
- 모두 변수와 함수를 가질 수 있다.
- 생성자를 가질 수 있다.
- 객체로 만들어 사용할 수 있다.

<br/>

-----------------

<br/>

### **2. C++**
- C++에서 **클래스**와 **구조체**의 가장 큰 차이점은 기본 접근제어자이다.
- **클래스** : private
- **구조체** : public

####  **예시**
```cpp
// 클래스
class A
{
	int x;	// private (기본)
};

// 구조체
struct B
{
	int x;	// public (기)
};
```

### **3. C#**
C++과 달리 C#에서의 구조체와 클래스는 차이점이 확실하다.

#### **C#의 구조체**
- **값 타입**으로 참조가 아닌 값 복사가 일어난다.
- null 값이 불가능하다.
- **상속이 불가능**하지만 **인터페이스** 구현은 가능하.

#### **C#의 클래스**
- **참조 타입**으로 **힙 영역**에 저장된다.
- 복사를 하면 참조 복사가 일어난다.
- null 값이 가능하다.
- **상속이 가능**하다.

#### **예시**
```csharp
// C#의 구조체
struct S
{
	public int x;
}

S a = new S { x = 10 };
S b = a;
b.x = 20;		// a.x == 10

// C#의 클래스
class C
{
	public int x;
}

C a = new C { x = 10 };
C b = a;
b.x = 20;		// a.x == 20
```
