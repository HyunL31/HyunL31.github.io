## [OZ 게임개발캠프] 13일차 (4 / 6)

### **1. Static**
- **static** : 프로그램에서 **딱 1개**만 생성된다.
	- 유니티 에디터에서 static을 사용하면 에디터가 종료될 때까지 남아있다.
	- 싱글톤 패턴 등에서 사용된다.
- **static 멤버 변수** : 클래스 내의 static 변수는 위험하다.
	- 전역 변수처럼 사용하는 경우가 많다. (매니저 클래스로 뺄 수도 있다.)
	- C#의 데이터 영역은 힙 영역이지만 GC가 돌지 않는 공간을 의미한다.
- 클래스 안이든 밖이든 코드 영역에 딱 1개만 전달된다.
- 다만 static은 this가 전달되지 않는 함수에 붙는다. (유틸 함수 등)
	- 별도의 객체 생성 없이 함수를 사용할 수 있다.

### **3. 박싱 & 언박싱**
- 참조 타입과 값 타입 사이에서의 형변환을 위해 박싱, 언박싱을 사용한다.
- **박싱** : 값 타입의 변수를 참조 타입의 객체로 만든다.
- **언박싱** : 참조 타입의 객체를 반대로 값 타입으로 만든다.
- 이 과정에서 힙에 객체가 생성되고 GC가 발생할 가능성이 있다.

```csharp
// 박싱
int cat = 10;
object boxCat = cat;

// 언박싱
int unboxCat = (int)boxCat;
```

### **5. 데일리 과제**
- **리스트 (List)** : 리스트는 선형 자료구조로 배열처럼 같은 자료형의 데이터를 순차적으로 저장하는 자료구조이다.
	- 배열과 달리 크기를 유동적으로 바꿀 수 있다.
	- `몬스터 리스트`, `아이템 인벤토리`, `덱 / 카드 시스템`, `친구 목록 / 랭킹 UI` 등에 사용된다.
```csharp
List<int> list = new List<int>();

for (int i = 0; i < 10; i++)
{
	list.Add(i + 1);
}

for (int i = 0; i < 10; i++)
{
	Console.WriteLine(list[i]);		// 1 ~ 10 출력
}
```

<br/>

- **연결리스트 (LinkedList)** : 연결리스트는 리스트와 비슷하지만 노드로 연결된 리스트이다.
	- 노드끼리의 연결만 바꿔주면 되기 때문에 데이터의 추가와 삭제가 빠르다.
	- 다만 순차적으로 접근하기 때문에 검색이 잦은 경우에는 그냥 리스트가 더 빠르다.
	- 주로 `객체 풀링`, `동적 관리` 등에서 사용되지만 보통은 그냥 리스트를 더 많이 사용한다.
```csharp
LinkedList<int> llist = new LinkedList<int>();

llist.AddLast(1);
llist.AddLast(2);
llist.AddFirst(3);		// 3 - 1 - 2 순으로 저장
```

<br/>

- **딕셔너리 (Dictionary)** : 딕셔너리는 키와 값을 쌍으로 저장할 수 있는 자료구조이다.
	- 데이터가 키와 값이 함께 저장되어 키를 통해 값을 쉽고 빠르게 불러올 수 있다.
	- 주로 `상태 / 설정 관리`, `객체 ID 관리`, `리소스 관리` 등에 사용된다.
```csharp
Dictionary<int, string> dict = new Dictionary<int, string>();

dict[1] = "멍멍이";
dict[2] = "야옹이";
dict[3] = "쮝쮝이";

Console.WriteLine(dict[1]);		// "멍멍이" 출력
``` 

<br/>

- **스택 (Stack)** : 스택은 **후입선출 (Last In First Out, LIFO)** 형태의 자료구조이다.
	- 가장 나중에 들어간 데이터가 가장 빨리 나온다.
	- 주로 `씬 / 상태 저장`, `플레이어 행동 기록`, `UI 뒤로가기` 등에 사용된다.
```csharp
Stack<int> st = new Stack<int>();

for (int i = 0; i < 10; i++)
{
	st.Push(i + 1);		// 1 ~ 10까지 순서대로 들어간다.
}

for (int i = 0; i < 10; i++)
{
	st.Pop();		// 10 ~ 1까지 반대로 나온다.
}
``` 

<br/>

- **큐 (Queue)** : 큐는 **선입선출 (First In First Out, FIFO)** 형태의 자료구조이다.
	- 스택과 반대로 먼저 들어간 데이터가 가장 먼저 나온다.
	- 주로 `대기열 처리`, `서버 요청 처리`, `대사 출력`, `공격 / 이벤트 처리`, `애니메이션 / 이펙트 처리` 등에 사용된다.
```csharp
Queue<int> que = new Queue<int>();

for (int i = 0; i < 10; i++)
{
	que.Enqueue(i + 1); 		// 1 ~ 10까지 순서대로 들어간다. 
}

for (int i = 0; i < 10; i++)
{
	que.Dequeue();		// 1 ~ 10까지 순서대로 나온다.
}
```

<br/>

- **집합 (HashSet)** : 집합이란 중복되지 않는 데이터들을 저장하는 자료구조이다.
	- 이미 집합 내에 있는 데이터가 다시 들어올 경우 자동으로 제거된다.
	- 주로 `아이템, 칭호 등 중복 방지`, `방문 체크`, `존재 확인`, `버프 관리` 등에 사용된다.
```csharp
HashSet<string> hs = new HashSet<string>();

hs.Add("전사 칭호");
hs.Add("힐러 칭호");
hs.Add("전사 칭호");		// 자동으로 무시된다.

foreach(string str in hs)
{
	Console.WriteLine(str);		// "전사 칭호", "힐러 칭호" 출력
}
```

<br/>

- **SortedList / SortedDictionary** : 리스트와 딕셔너리이지만 데이터를 자동으로 정렬해주는 자료구조이다.

<br/>

- **제네릭 (Generic)** : 타입을 컴파일 타임에 미리 받아 형 변환이 필요 없어 안전하다. (위의 자료구조들)
- **논제네릭 (Non-Generic)** : 제네릭과 반대로  모든 타입을 object로 받기 때문에 형 변환이 필요하고 런타임에 오류를 검사한다.
	- `ArrayList`, `HashTable` 등이 논제네릭 자료구조이다.
	- 사실상 잘 사용하지 않는 형태의 자료구조이다.
	- 논제네릭은 박싱과 언박싱이 발생한다.
