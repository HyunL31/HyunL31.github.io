## [OZ 게임개발캠프] 11일차 (4 / 2)

### **1. var 타입**
- **var 타입**: 자료형을 알아서 자동으로 결정해주는 자료형이다.
- 편리하지만 가독성이나 유지 보수 등에서 문제가 될 수 있기에 기본 자료형에서는 잘 쓰지 않는다.
- 동적 할당처럼 뒤에 명시적으로 자료형이 나와있는 경우에 주로 사용한다.
- 컴파일 타입에 자료형이 결정된다.

#### **예시**
```csharp
// 기본 자료형에서는 굳이 var 타입을 사용하지 않는다.
// 오히려 가독성과 유지보수성을 해친다.
var name = "몬스터";
var age = 24;
var isAlive = false;

// 뒤에 타입이 명확하니 var 타입을 사용해도 된다.
var monster = new Monster();
```

### **2. 클래스 & 구조체**
- **C++**에서의 클래스와 구조체는 큰 차이가 없다.
- **C#**에서는 클래스와 구조체가 아예 다르다.
	- **구조체 (Structure)** : 값 타입으로 **스택 메모리**에 저장되고 **값 복사**가 일어난다.
	- **클래스 (Class)** : 참조 타입으로 **힙 메모리**에 저장되고 **참조 전달**이 일어난다.
	- 클래스 뿐만 아니라 구조체를 사용할 때도 new 키워드를 사용하지만 여전히 구조체는 스택 메모리에 저장된다.
	- 다만 delete 키워드로 소멸자를 불러오지 않고 가비지 콜렉터를 이용한다는 점이 C++과 다르다.

### **3. 값 타입 & 참조 타입**
- **값 타입** : **스택 메모리**에 저장되고 **값 복사**가 일어난다.
	- 값의 원본이 바로 바뀌는 것이 아니라 똑같은 값의 변수가 복사되어 전달된다.
	- 스코프 범위를 넘어가면 자동으로 메모리에서 사라진다.

<br/>

- **참조 타입** : **힙 메모리**에 저장되고 **참조 전달**이 일어난다.
	- 변수 원본의 주소가 전달되어 원본이 바로 바뀐다.
	- 참조가 끊기면 GC가 나중에 처리한다.
	- `string`은 참조 타입!!

### **4. 상속**
- C#에서 다중 상속은 불가능하다. 그래서 인터페이스를 사용하기도 한다.
	- **인터페이스**는 데이터가 없고 기능만 있다.
	- 클래스처럼 인터페이스를 상속받아 그 기능을 사용할 수 있다. 
-  오버라이딩 할 때 base 키워드를 사용하면 부모 클래스의 함수를 사용할 수 있다.

```csharp
public class Parent
{
	private string _name;
	
	public virtual void SpeakName()
	{
		Console.WriteLine($"{this._name}입니다.");
	}
}

public class Child : Parent
{
	private string _extraName;

	public override void SpeakName()
	{
		base.SpeakName();
		Console.WriteLine($"별명은 {this._extraName}입니다.");
	}
}
```

### **5. 데일리 과제**

```csharp
using System;

namespace DailyAssignmentCSharp
{
    internal class MagicSchool
    {
        public enum Dorm
        {
            None,
            Slytherin,
            Gryffindor,
            Hufflepuff,
            Ravenclaw
        }

        public class Wizard
        {
            private string _name;
            private int _age;
            private Dorm _dormitory;

            public Wizard(string name, int age, Dorm dormitory)
            {
                this._name = name;
                this._age = age;
                this._dormitory = dormitory;
            }

            public string GetName()
            {
                return this._name;
            }

            public virtual void PrintWizard()
            {
                Console.WriteLine($"- 이름: {this._name}\n- 나이: {this._age}\n- 기숙사: {this._dormitory}");
            }
        }

        public class Student : Wizard
        {
            private int _power = 0;

            public Student(string name, int age, Dorm dormitory) : base(name, age, dormitory) { }

            public void LearnMagic(string magic, Professor professor)
            {
                Random random = new Random();
                int randomNum = random.Next(0, 2);

                if (randomNum == 0)
                {
                    Console.WriteLine($"{base.GetName()}은(는) {magic} 주문을 배웠습니다!");

                    this._power += professor.GetTeachingPower();
                    professor.SetTeachingPower(10);
                }
                else
                {
                    Console.WriteLine($"{base.GetName()}은(는) {magic} 주문을 배우지 못했습니다....");

                    professor.SetTeachingPower(-10);
                }
            }

            public override void PrintWizard()
            {
                Console.WriteLine("==========학생=========");
                base.PrintWizard();
                Console.WriteLine($"- 마력: {this._power}");
            }
        }

        public class Professor : Wizard
        {
            private int _teachingPower = 0;

            public Professor(string name, int age, Dorm dormitory) : base(name, age, dormitory) { }

            public void SetTeachingPower(int teachingPower)
            {
                this._teachingPower += teachingPower;
            }

            public int GetTeachingPower()
            {
                return _teachingPower;
            }

            public void TeachMagic(string magic, Student student)
            {
                Console.WriteLine($"{base.GetName()}은(는) {magic} 주문을 가르쳤습니다.");

                student.LearnMagic(magic, this);
            }

            public override void PrintWizard()
            {
                Console.WriteLine("==========교수=========");
                base.PrintWizard();
                Console.WriteLine($"- 교수력: {this._teachingPower}");
            }
        }

        static void Main(string[] args)
        {
            Student student = new Student("해리포터", 11, Dorm.Gryffindor);

            Professor professor = new Professor("맥고나걸", 56, Dorm.Gryffindor);
            professor.SetTeachingPower(30);

            student.PrintWizard();
            professor.PrintWizard();

            professor.TeachMagic("변신술", student);

            student.PrintWizard();
            professor.PrintWizard();
        }
    }
}
```
