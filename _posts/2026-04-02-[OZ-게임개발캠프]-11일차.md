### **2. Class 간의 상호작용**
```csharp
public class Monster
{
	public int m_speed = 10;
}

public class Food
{
	public void Eat(Monster monster)
	{
		monster.m_speed += 5;		// 캡슐화가 깨진다. & private에 접근 불가
	}
}
```

<br/>

```csharp
public class Monster
{
	private int m_speed = 10;

	public void SpeedUp()
	{
		this.m_speed += 5;
	}
}

public class Food
{
	public void Eat(Monster monster)
	{
		monster.SpeedUp();		// 수동태로 구현
	}
}
```
