## 사전캠프 - C# 연산자

### **1. 연산자**
**연산자**란 값과 값 사이에서 무언가를 계산하거나 판단하게 도와주는 기호를 의미한다.
수학에서의 ```+```, ```-```, ```*```, ```%``` 등이 그 예시이다.

#### **예시**
```csharp
int age = 20;

if (age >= 18)	// 연산자를 활용한 비교
{
	Console.WriteLine("성인입니다.");
}
```

### **2. 연산자의 종류**

#### **산술 연산자**
사칙연산 등 숫자를 계산할 때 사용하는 연산자이다.

| 연산자 | 의미 |
|--------|----------|
| + | 더하기 |
| - | 빼기 |
| * | 곱하기 |
| / | 나누기 |
| % | 나머지 |

#### **비교 연산자**
양쪽 값을 비교해 참과 거짓을 판단할 때 사용하는 연산자이다.

| 연산자 | 의미 |
|--------|----------------|
| == | 같다 |
| != | 같지 않다 |
| > | 크다 |
| < | 작다 |
| >= | 크거나 같다 |
| <= | 작거나 같다 |

#### **논리 연산자**
어떤 조건들을 연결할 때, 동시에 비교할 때 사용하는 연산자이다.

| 연산자 | 의미 |  
|--------|-----------------|  
| && | 그리고 (AND) |  
| \|\| | 또는 (OR) |  
| ! | 아니다 (NOT) |

### **3. 과제**
```
어떤 사람의 나이(age)가 65세 이상이거나, 또는 VIP회원(isVip)이면 우대 대상입니다.
①, ②에 맞는 연산자를 작성하세요.
age ( ① ) 65 ( ② ) isVip == true
```

#### **소스코드**
```csharp
namespace OZcoding
{
    internal class Program
    {
        static void Main(string[] args)
        {
            bool priority = false;
            int age = 65;
            bool isVip = true;

            if (age >= 65 || isVip == true)
            {
                priority = true;
            }

            if (priority)
            {
                Console.Write("우대 대상입니다.");
            }
            else
            {
                Console.Write("우대 대상이 아닙니다.");
            }
        }
    }
}
```
