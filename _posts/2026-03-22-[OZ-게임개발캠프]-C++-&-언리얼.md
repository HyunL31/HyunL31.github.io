## [OZ 게임개발캠프] 2일차 (03 / 20)

### **1. 소프트웨어**
- **하드웨어** : 컴퓨터, 콘솔 게임기와 같은 기계 장치
- **소프트웨어** :  하드웨어로 실행할 수 있는 모든 프로그램
	- 일종의 뇌와 같은 역할로 하드웨어에게 뭘 해야 하는지 알려준다. 

<br/>

-----------------

<br/>

### **2. 프로그래밍 언어**
- **기계어** : 0과 1로 이루어진 컴퓨터가 이해할 수 있는 언어 (Low level code, Native)
- **고수준 언어 (High level language)** : 인간의 언어에 가까운 프로그래밍 언어 
- **컴파일러** : 고수준 언어를 기계어로 변환해주는 프로그램

<br/>

- `고수준 언어` → `컴파일러` → `어셈블리` → `기계어` 순으로 변환되어 최종적으로 컴퓨터가 기계어를 읽고 소프트웨어를 실행한다.

<br/>

-----------------

<br/>

### **3. 운영체제 (OS : Operating System)**
- **운영체제** : 사용자가 컴퓨터를 쉽고 효율적으로 사용할 수 있도록 돕는 소프트웨어
	- 여러 소프트웨어를 쉽게 실행할 수 있도록 도와주는 플랫폼
	- 하드웨어 (메모리, CPU)와 사용자 사이의 다리 역할을 수행하는 관리자
	- IOS의 페이스북과 Android의 페이스북은 하드웨어 관점에서 동일한 프로그램이 아니다.

<br/>

- **운영체제의 역할**
	-  각 프로그램 별로 메모리와 CPU 사용에 대한 순서를 정리해준다.
	- 컴파일러가 변환한 코드를 실행한다.
	- 실제로 소프트웨어를 실행하는 플랫폼 역할을 한다.

<br/>

- `IOS`, `Android`, `Windows` 등이 있다.

<br/>

### **4. 네이티브 언어 (컴파일러 기반 언어)**

	- **장점** : 기계어 (하드웨어)에 가까운 언어이기 때문에 실행 속도가 빠르다.
	- **단점** : 다른 운영체제에서 실행하기 위해서는 소스코드를 변경하거나 API가 필요하다.

<br/>

- `C`, `C++`, `Swift` 등이 있다.

### **5. 가상 머신 기반 언어**
- **가상 머신** : 프로그래밍 언어를 기계어로 바로 변환하지 않고 중간 언어로 변환한 코드를 실행하는 프로그램
- **매니지드 언어** : 바로 기계어로 변환되지 않고 가상 머신을 통해 중간 언어로 변환된 뒤 실행되는 언어
	- **장점** : 운영체제나 플랫폼에 맞추지 않아도 된다.
	- **단점** : 중간에 가상 머신을 거쳐야 하기 때문에 실행 속도가 비교적 느리다.

<br/>

#### **자료형과 크기**
| 타입   | 크기 (byte / bit) | 예시 값              | 설명     |

### **7. 메모리**
- **RAM** : 임시 기억 장치
- RAM은 프로그램을 실행하는 동안에만 내용을 기억한다.
- 모든 프로그램이 임시 기억 장치에 변수 등을 저장한다.
- RAM에 저장된 임시 기억은 필요한 경우 저장 작업을 통해 SSD, HDD 등과 같은 장기 기억 장치에 저장된다.

<br/>

#### **스택 메모리 (Stack)**
- 아래에서부터 차곡차곡 쌓인 더미 형태
- 스택 메모리에 저장되는 데이터들은 밑에서부터 위로 쌓이며 가장 나중에 들어온 데이터가 가장 먼저 나간다.
- 실행 속도가 빠르고 자동적으로 관리된다.
	- 변수가 함수 범위를 벗어나면 자동으로 사라지는 이유
- 지역 변수나 함수 호출 정보가 스택 메모리에 저장된다.

<br/>

#### **힙 메모리 (Heap)**
- 마구잡이로 쌓인 채 공중을 떠다니는 더미 형태
- 힙 메모리에 저장되는 데이터들은 사용자가 저장되는 위치를 제어할 수 없다.
- 동적으로 생성되는 객체는 힙 메모리에 저장된다.
- 개발자가 수동으로 메모리 할당, 해제를 해주어야 하며 속도가 상대적으로 느리다.
- C++에서는 new, delete 키워드를 사용해 힙 메모리를 할당하고 해제한다.
	- C#에서는 delete를 따로 하지 않아도 가비지 콜렉터가 자동으로 사용하지 않는 메모리를 해제한다.
	- GC가 너무 많으면 렉이 걸릴 수 있으니 적절히 처리해주어야 한다.

### **8. 데일리 과제**

```cpp
#include <iostream>
#include <string>

using namespace std;

int score = 0;

// 마법 주문 별 점수를 계산하는 함수
int CalculateScore(string magic)
{
	int extraScore = magic.length();

	return extraScore;
}

// 주문 성공 여부를 판단하는 함수
bool TextMagicAbility(string correct)
{
	cout << correct << " 주문을 입력하세요.\n";

	string userInput;
	// cin >> userInput;	"cin >> "은 공백 직전까지 입력 받음
	getline(cin, userInput);	// #include <string>

	if (correct == userInput)
	{
		score += CalculateScore(correct);
	
		return true;
	}

	return false;
}

// 기숙사 배정 함수
string AssignDorm(int total)
{
	string dormitory = "";

	if (total >= 60)
	{
		dormitory = "레번클로";
	}
	else if (total >= 45)
	{
		dormitory = "슬리데린";
	}
	else if (total >= 30)
	{
		dormitory = "그리핀도르";
	}
	else
	{
		dormitory = "후플푸프";
	}

	return dormitory;
}

int main()
{
	string magicArr[6] = {"Avada Kedavra", "Wingardium Leviosa", "Lumos", "Aquamenti", "Expelliarmus", "Stupefy"};

	for (int i = 0; i < 6; i++)
	{
		if (!TextMagicAbility(magicArr[i]))
		{
			cout << "점수를 얻지 못했습니다.\n";
		}
		else
		{
			cout << "주문에 성공했습니다.\n";
		}

		cout << "\n";
	}

	cout << "당신은 " << AssignDorm(score) << "에 배정되었습니다.\n";

	return 0;
}
```

### **3. 연산자 (Operator)**
- **연산자** : 변수에 대한 비교, 계산 등의 여러 연산을 수행하게 하는 명령 (`+`, `<`, `||` )
	- 연산자가 CPU에게 명령하여 변수들의 연산이 수행된다.
	- **연산** : 식이 표현한 일정한 규칙에 따라 계산하는 것

#### **연산자의 종류**
- **산술 연산자** : `+`, `-`, `*`, `/`, `%` (짝수 / 홀수 판별, 아이템 드랍 확률 계산)
- **대입 연산자** : `=`, `+=`, `-=`, `*=`, `/=` (오른쪽 값을 왼쪽 값에 저장)
- **증감 연산자** : `++`, `--` (값을 1만큼 변경)
- **비교 연산자** : `==`, `>=`, `<=`, `!=`, `>`, `<` (결과는 bool 값)
- **논리 연산자**: `&&`, `||`, `!` (여러 조건을 동시에 연산)

### **5. 데일리 과제**

```cpp
#include <iostream>

using namespace std;

int day = 30;

enum State
{
	Alive,
	Death,
	Clear
};

class Player
{
public:
	string name;
	int hp;
	int food;
	int water;
	State state;

//private:
	// 지피티: Player 클래스 밖에서 생성자를 사용하고 있기 때문에 private으로 만들면 안된다.
	Player(string name, int hp, int food, int water, State state)
	{
		this->name = name;
		this->hp = hp;
		this->food = food;
		this->water = water;
		this->state = state;
	}
};

// 지피티: 매개변수는 값 복사이기에 변화가 반영되지 않는다. (그냥 Player player는 값 복사, &를 붙여줘야 참조 복사)
// 값을 바꾸지 않고 출력을 하는 함수이기에 만약을 대비해 const(상수) 추가
void CurrentState(const Player& player)
{
	cout << "-------------------------------------------------\n"
		<< "플레이어 이름: " << player.name << "\n" << "체력: " << player.hp << "\n" << "음식 지수: " << player.food << "\n" << "물 지수: " << player.water << "\n"
		<< "-------------------------------------------------\n";
}

// 값을 바꾸는 함수이므로 상수 X
void CheckState(Player& player)
{
	if (day <= 0 && player.hp > 0)
	{
```

### **5. 포인터 (Pointer)**
- **포인터** : 특정 메모리의 위치를 가리키는 특정 주소 (포인터도 특별한 자료형이다.)
- **포인터 변수** : 포인터를 담는 변수
	- 포인터 변수를 한 번 선언하면 주소만 바꾸어 다른 메모리에 접근할 수 있다.

#### **예시**
```cpp

*dogPointer = 20;		// 변수 dog의 값이 20으로 바뀜

// 오류 발생
dogPointer = 20;		// 포인터 변수도 특정 자료형이라 할 수 있는데 정수형 데이터가 대입되었기에 오류 발생

// 배열
cout << arr;				// 0번째 배열의 주소
cout << arr + 1;		// 1번째 배열의 주소값
cout << *(arr + 1) << " " << arr[1];		// 둘 다 같은 1번째 배열의 값
```

### **6. 값 전달 & 참조 전달**
- **값 전달** : 변수를 복사하여 전달
- **참조 전달** : 변수의 주소값을 전달하여 원본에 접근 (반환 없이 변수의 값을 바꾸는 방법)

#### **예시**
```cpp
// 값 전달
void AddValue(int money)
{
	money += 100;
}

// 참조 전달
void AddReference(int& money)
{
	money += 100;
}

int main()
{
	int money = 50;

	AddValue(money);
	cout << money;	// 50 (값 전달이기에 복사본을 전달하여 원본에는 영향 X)

	AddReference(money);
	cout << money;	// 150 (변수의 원본에 접근하였기 때문에 값이 변경)
}
```

### **2. 접근 제한자 & Getter/Setter**
- **접근 제한자** : 외부의 접근 권한을 분류하여 객체를 보호하기 위한 키워드
	- 클래스, 구조체, 언어에 따라 기본으로 부여되는 접근 제한자가 다르다.
	- **public** : 모든 외부에서 접근 가능
	- **private** : 같은 클래스에서만 접근 가능
		- **[SerializedField]** : 유니티에서 private로 선언할 시 이 키워드를 사용하면 인스펙터에서는 볼 수 있다.

<br/>

- **Getter / Setter** : private으로 선언된 멤버에 접근하기 위해 만든 메서드
	- 따라서 Getter, Setter 메서드는 public으로 선언
	- **Getter** : private으로 선언된 멤버를 가져와서 사용하기 위한 메서드
	- **Setter** :	private으로 선언된 멤버를 변경하기 위한 메서드

#### **예시**
```cpp
class Example
{
private:
	string name;
	int age;
	double height, weight;

public:
	// Getter
	int GetAge()
	{
		return age;
	}
	
	// Setter
	void SetAge(int newAge)
	{
		age = newAge;
	}

	void ShowAge()
	{
		cout << GetAge();
	}
};
```

### **5. 객체 지향 (Object Oriented Programming)**
- 현실의 개체를 객체로 모델링하여 그 객체들의 상호작용으로 프로그래밍하는 방식

#### **객체 지향 4대 특징 (요게 더 중요 : 면접)**
- **상속** : 부모 클래스의 기능을 자식 클래스가 물려받는 것
	- 폴더와 마찬가지이기 때문에 깊이가 너무 깊을 경우 오히려 유지보수가 어려워진다.
- **다형성** : 하나의 이름이 상황에 따라 다르게 동작하는 것 **(오버로딩 & 오버라이딩)**
- **캡슐화** : 데이터와 기능을 하나로 묶고 외부에서 직접 접근하지 못하게 숨기는 것
- **추상화** : 내부 원리를 몰라도 사용할 수 있도록 복잡한 내부 구현을 숨기고 핵심 인터페이스만 보여주는 것

#### **객체지향 5대 원칙 (SOLID)**
- **단일 책임 원칙** : 클래스는 딱 하나의 책임만을 가져야 한다.
- **개방 폐쇄 원칙** : 확장에는 열려있고 수정에는 닫혀있어야 한다.
- **리스코프 치환 원칙** : 자식 클래스는 언제나 부모 클래스를 대체할 수 있어야 한다.
- **인터페이스 분리 원칙** : 자신이 사용하지 않는 기능은 구현하지 않아야 한다.
- **의존 역전 법칙** : 구체적인 것보다 추상적인 것에 의존해야 한다.

### **6. 오버라이딩 & 오버로딩**
- **오버라이드 (Override)** : 자식 클래스에서 부모 클래스의 기능을 덮어쓸 수 있는 기능(메서드 재정의)
	- `C#`에서는 `base` 키워드
	- `virtual` 키워드는 오버라이드를 할 수 있는 함수라고 명시

<br/>

- **오버로드 (Overload)** : 이름과 반환 자료형은 같은 함수이지만 파라미터의 자료형, 개수가 다른 메서드를 만드는 기능 (암기)
	- ex. `Debug.Log("Hello, World!");`, `Debug.Log("Hello, World!", this);`

```cpp
#include <iostream>

using namespace std;

enum Type
{
	Deal,
	Tank,
	Heal
};

class Character
{
public:
	string name;
	Type type;
	int hp;
	int atk;
	int def;

	Character(string name, Type type, int hp, int atk, int def)
	{
		this->name = name;
		this->type = type;
		this->hp = hp;
		this->atk = atk;
		this->def = def;
	}

	~Character(){}

	virtual void Attack(){}

	void TakeDamage(Character* target)
	{
		cout << target->name << "이(가) 공격을 받았습니다.\n";

		int random = rand() % 150;

		// 제미나이의 수정: 나누기 사용할 때 조심하기!!
		// 0으로 나눌 경우 바로 런타임 에러 발생 (+1 해주거나 max() 함수 사용하기)
		int damage = (this->atk / (target->def / 10 + 1)) + random;
		target->hp -= damage;

		cout << target->name << "이(가) -" << damage << "데미지를 받았습니다.\n\n";
	}

	void Dead()
	{
		cout << name << "이(가) 사망했습니다.\n\n";
	}
};

// 상속에도 접근 제어자가 있다...?
// C++에서 클래스는 기본적으로 private으로 상속
// 구조체가 public으로 상속
class Archer : public Character
{

	}
};

	}

{
public:

	~Priest(){}

	void Attack() override
	{
		int random = rand() % 30;

		cout << name << "가 열심히 마법으로 공격합니다.\n" << "동시에 치료를 시작합니다.\n";

		this->hp += random;

		cout << name << "의 HP가 " << random << "증가했습니다.\n";
	}
};

int main()
{
	cout << "----------------------    " << "세 낭만 용사" << "    ----------------------\n";

	srand(time(0));

	Priest* priest = new Priest();
	Archer* archer = new Archer();
	Guardian* guardian = new Guardian();

	int userInput;

	while (true)
	{
		cout << "----------------------\n" << "당신의 캐릭터를 선택해주세요.\n" << "1. 궁수   2. 가디언   3. 프리스트\n" << "----------------------\n";
		cin >> userInput;

		if (userInput < 1 || userInput > 3)
		{
			cout << "잘못된 번호입니다. 다시 선택해주세요.\n";
			continue;
		}
		else
		{
			break;
		}
	}

	Character* warriors[3] = { priest, archer, guardian };

	Character* player = nullptr;

	if (userInput == 1)
	{
		player = archer;
	}
	else if (userInput == 2)
	{
		player = guardian;
	}
	else
	{
		player = priest;
	}

	int dead = 0;

	while (dead < 2)
	{

		for (int i = 0; i < 3; i++)
		{
			if (warriors[i]->hp <= 0)
			{
				continue;
			}

			for (int j = 0; j < 3; j++)
			{
				if (i == j || warriors[j]->hp <= 0)
				{
					continue;
				}

				warriors[i]->Attack();
				warriors[i]->TakeDamage(warriors[j]);

				if (warriors[j]->hp <= 0)
				{
					warriors[j]->Dead();

					dead++;
				}

				if (dead >= 2)
				{
					break;
				}
			}

			cout << "----------------------------\n";

			for (int j = 0; j < 3; j++)
			{
				cout << warriors[j]->name << ": ";

				if (warriors[j]->hp <= 0)
				{
					cout << "사망\n";
				}
				else
				{
					cout << warriors[j]->hp << "\n";
				}
			}

			cout << "----------------------------\n";

			if (dead >= 2)
			{
				break;
			}
		}
	}

	Character* winner = nullptr;

	for (int i = 0; i < 3; i++)
	{
		if (warriors[i]->hp > 0)
		{
			winner = warriors[i];
		}
	}

	cout << "승자는 " << winner->name << "입니다.\n";

	if (winner == player)
	{
		cout << "당신이 승리했습니다. 축하합니다.\n";
	}
	else
	{
		cout << "당신은 승리하지 못했습니다. Game Over!!\n";
	}

	// 까먹고 안한 부분...
	// new 키워드로 생성한 메모리는 힙 영역에 저장
	// 힙 영역에서는 스택 영역과 반대로 자동으로 메모리 해제가 안된다.
	// 따라서 delete로 메모리 해제를 꼭 해줘야 한다.
	// delete 키워드 사용 시 자동으로 소멸자가 실행된다.
	delete priest;
	delete archer;
	delete guardian;

	return 0;
}
```

```cpp
		this->isAlive = isAlive;

		this->def = def;

		}
	}

			nx--;
		}

			nx++;
		}

		{
			ny--;
		}
		else if (userInput == 'D' || userInput == 'd')
		{
			ny++;
		}
		else
		{
			cout << "잘못된 입력입니다.\n다시 입력해주세요.\n";

			continue;
```
