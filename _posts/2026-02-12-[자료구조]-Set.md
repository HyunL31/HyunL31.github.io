## Set (집합)

### **1. Set이란?**
**Set**이란 중복을 허용하지 않고 순서가 없는 원소들의 집합이다.
Set은 수학에서의 집합으로 사용된다.

<br/>

-----------------

<br/>

### **2. Set의 특징**
- 중복이 허용되지 않는다.
- 자동으로 **정렬**이 된다. (오름차순)
- 탐색, 삽입, 삭제가 $O(log n)$에 가능하다.

<br/>

-----------------

<br/>

### **3. Set의 종류**
**(1) C++**
- ```std::set``` : 이진 균형 트리인 Red - Black Tree로 구현된다.
```cpp
#include <set>
set<int> s;

s.insert(1);
```
- ```std::unordered_set``` : 해시 테이블 기반으로 구현된다.
```cpp
// 자동으로 정렬이 되지 않는다.
// 평균 O(1)의 시간복잡도를 갖는다.
#include <unordered_set>
unordered_set<int> us;
```

<br/>
 
 
**(2) C#**
- ```HashSet<T>``` : 해시 테이블 기반으로 구현된다.
```csharp
// 자동으로 정렬이 되지 않는다.
// 평균 O(1)의 시간복잡도를 갖는다.
HashSet<int> set = new HashSet<int>();

set.Add(3);
set.Add(1);
set.Add(3);
```

- ```SortedSet<T>``` : Red - Black Tree로 구현된다.
```csharp
// 자동으로 정렬된다.
// 평균 O(log n)의 시간복잡도를 갖는다. 
SortedSet<int> sorted = new SortedSet<int>();
```
