## 월드 좌표 & 로컬 좌표

### **1. 좌표란?**
**좌표**란 어떤 점의 위치를 수치로 표현한 것을 의미한다.
보통 원점을 교차하며 서로 직각인 X, Y, Z축을 설정하고 그 축을 기준으로 원점으로부터 얼마나 떨어져 있는지 숫자로 표현한다.

월드 좌표와 로컬 좌표는 이 원점과 축을 어떤 기준으로 설정하는지에 따라 달라진다. 

<br/>

-----------------

<br/>

### **2. 월드 좌표 (World Coordinate)**
**월드 좌표**란 절대적인 위치로 게임 세계 전체에서의 좌표를 의미한다.
월드를 기준으로 오브젝트가 월드의 어느 위치에 있는지를 표현한다.

<br/>

-----------------

<br/>

### **3. 로컬 좌표 (Local Coordinate)**
**로컬 좌표**란 상대적인 위치로 부모 오브젝트나 자기 자신을 기준으로 두는 좌표이다.
부모 오브젝트에서 얼마나 떨어져 있는지, 혹은 자기 자신의 어느 부분에 위치한 오브젝트인지를 의미한다.

<br/>

-----------------

<br/>

### 4. 예시
Player와 Sword가 있을 때,
```
Player의 월드 좌표 : (10, 0, 0)
Sword의 로컬 좌표 : (1, 0, 0)

Sword의 월드 좌표 : (11, 0, 0)
```
