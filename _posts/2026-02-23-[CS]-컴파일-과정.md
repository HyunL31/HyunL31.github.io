## 컴파일 순서

### **1. 전처리 (Preprocessing)**
**전처리**란 프로그램 상단에 작성되는 헤더파일 등의 전처리 지시문을 변환하는 과정이다.
이 과정을 통해 확장된 C++ 파일(.i)을 얻을 수 있다.

#### **예시**
```cpp
#include <iostream>  
#define PI 3.14
```

<br/>

-----------------

<br/>

### **2. 컴파일 (Compiling)**
**컴파일**이란 C++ / C# 등의 고급 언어를 **어셈블리어**로 변환하는 과정이다.
`어휘 분석` → `구문 분석` → `의미론적 분석` → `중간 코드 생성` → `최적화` → `어셈블리 코드 생성`
위의 순서로 컴파일이 진행되며 문법과 타입을 검사하고 최적화를 수행한다.
이 과정을 통해 어셈블리 코드로 작성된 파일(.s)를 얻을 수 있다.

#### **예시**
```cpp
int  a = 10;		// → 이 코드를 컴파일하면 어셈블리어로 변환된다.
```

<br/>

-----------------

<br/>

### **3. 어셈블러 (Assembler)**
**어셈블러**가 위에서 생성된 어셈블리어를 기계어로 바꿔준다.
아직 함수의 주소가 확정되지 않아 실행할 수 없다.
이 과정에서 오브젝트 파일(.o)을 얻을 수 있다.

<br/>

-----------------

<br/>

### **4. 링크 (Linking)**
**링크**는 여러 개의 오브젝트 파일을 하나로 합치고 라이브러리를 연결하는 과정이다.
이때 함수 주소가 결정되고 실행 가능한 파일을 얻을 수 있다.
