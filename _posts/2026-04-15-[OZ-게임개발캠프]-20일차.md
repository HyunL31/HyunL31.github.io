## [OZ 게임개발캠프] 20일차 (4 / 15)

### **1. 델리게이트 (Delegate)**
- **델리게이트 (대리자)** : 함수의 포인터와 같다. 일종의 자료형처럼 사용된다.
- 함수를 일종의 변수처럼 사용할 수 있다.
- 클래스 외부에서도 마음대로 호출하거나 수정할 수 있다.
- **Action** : 반환형이 void일 때, 사용할 수 있는 델리게이트
- **Func** : 반환형이 있을 때, 사용할 수 있는 델리게이트
	- Action과 Func가 간단해서 일반 델리게이트보다 많이 사용된다.

#### **예시**
```csharp
public delegate void MakePizza();
  
MakePizza pizza;

pizza = BakeCheesePizza;
pizza += BakePepperoniPizza;

pizza();
```

### **2. 이벤트**
- **이벤트** : 어떤 일이 발생했을 때 자동으로 특정 메서드가 실행되게 하는 것
	- 델리게이트를 기반으로 만들어진 구조이다.
- **이벤트 구독** : 이벤트가 발생했을 때 실행할 메서드를 등록하는 것
	- `+=` 연산자를 사용한다.
- **이벤트 발생** : 이벤트를 실제로 실행시키는 것
	- 보통 이벤트를 가진 클래스 내부에서만 호출한다

### **3. 데일리 과제**
```csharp
using System;

namespace DailyAssignmentCSharp
{
    internal class Event
    {
        public class Player
        {
            public string Name { get; set; }

            public void WakeUp(int hour)
            {
                Console.WriteLine($"{this.Name}은(는) {hour}에 일어났습니다.");
            }

            public void Lazy(int hour)
            {
                Console.WriteLine($"{this.Name}은(는) {hour}에도 일어나지 않고 게으르게 누워있습니다.");
            }
        }

        public class Alarm
        {
            public event Action<int> OnAlarm;

            public void Morning(int hour)
            {
                Console.WriteLine($"오전 {hour}시입니다. 일어날 시간입니다.");
                OnAlarm?.Invoke(hour);
            }
        }

        static void Main(string[] args)
        {
            Alarm alarm = new Alarm();

            Player player1 = new Player();
            Player player2 = new Player();

            player1.Name = "까르륵";
            player2.Name = "아하하";

            // 여기에 매개변수 넣는 게 아니라 Invoke 할 때 들어감!
            alarm.OnAlarm += player1.WakeUp;
            alarm.OnAlarm += player2.Lazy;

            alarm.Morning(8);
        }
    }
}
```
