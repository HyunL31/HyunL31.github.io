### **2. 함수의 구조**
- **Main** : 프로그램의 시작점
- **Return Type** : 함수의 결과 값 자료형을 지정 (반환 값이 없다면 `void`)
- **Parameter** : 함수 기능에 필요한 변수들을 가져오기 위한 매개변수 (함수의 재료)
- **{  }** : 함수의 범위 (Scope)
- 함수의 반환 값은 원칙적으로 하나이지만 튜플을 통해 임시로 값을 여러 개 반환할 수 있다.
```csharp
(string  name, int  age) GetUser()  	// Tuple (튜플)
{  
	return ("홍길동", 20);  
}
```
```cpp
tuple<string, int>  GetUser()  
{  
	return {"홍길동", 20};  
}
```

<br/>

#### **예시**
```cpp
int CalculateScore(string magic)
{
	int extraScore = magic.length();

	return extraScore;
}
```

### **3. 클린 코드 (Clean Code)**
- 타인이 쉽게 이해할 수 있고 효율적으로 작성된 코드를 `클린 코드`라 한다.
- 함수는 단 하나의 역할만을 담당하도록 구현되어야 한다.
- 변수와 함수의 이름은 다른 사람도 쉽게 이해할 수 있도록 직관적으로 지어야 한다.

### **4. 변수 (Variable)**
- **변수** : 지정된 타입의 값을 저장할 수 있는 그릇 (값 변동 가능)
- 함수의 범위가 끝나면 결과값만 남고 그 안에서 선언된 변수는 자동으로 사라진다.

#### **변수의 구조**

### **5. 상수 (Constant)**
- **상수** : 값을 바꿀 수 없는 변수
- 다른 누군가가 값을 절대 바꾸지 않기를 원할 때 주로 사용한다.

#### **예시**
```cpp
readonly int a = 10;		// 런타임에 값이 고정 (생성자에서 변경 가능, C#)
const int a = 10;				// 컴파일 타임에 값이 고정
Literals		// 코드에 직접 작성하는 값 (10, "Hello", true)
enum Day { Monday, Tuesday };			// 사용자 정의 상수 집합
string s = "ABC";		// 문자열을 불변 객체 (C# 기준)
```

### **6. 자료형 (Data Type)**
- 자료형에 따라 메모리 사용량과 표현 범위가 달라진다.

#### **자료형과 크기**
| 타입 | 크기 (byte / bit) | 예시 값 | 설명 |  
|--------|-------------------|----------------------------|----------|  
| bool | 1 byte / 8 bit | true, false | 논리형 |  
| short | 2 byte / 16 bit | 0, 1, 2, 3, 4 | 정수형 |  
| char | 2 byte / 16 bit | 'a', 'b', 'c' | 문자형 |  
| int | 4 byte / 32 bit | 0, 1, 22, 34 | 정수형 |  
| float | 4 byte / 32 bit | 0.1, 2.34, 1.99 | 실수형 |  
| double | 8 byte / 64 bit | 0.1111111111 | 실수형 |

(C# 기준, C++에서 char는 1byte)

- main() 반환 값이 0이면 정상 종료를 의미
- 0은 false를 의미
- 1은 true를 의미
- 에러 테스트 반환 시에는 -1을 사용

### **7. 메모리**
- **RAM** : 임시 기억 장치
- RAM은 프로그램을 실행하는 동안에만 내용을 기억한다.
- 모든 프로그램이 임시 기억 장치에 변수 등을 저장한다.
- RAM에 저장된 임시 기억은 필요한 경우 저장 작업을 통해 SSD, HDD 등과 같은 장기 기억 장치에 저장된다.

<br/>

#### **스택 메모리 (Stack)**
- 아래에서부터 차곡차곡 쌓인 더미 형태
- 스택 메모리에 저장되는 데이터들은 밑에서부터 위로 쌓이며 가장 나중에 들어온 데이터가 가장 먼저 나간다.
- 실행 속도가 빠르고 자동적으로 관리된다.
	- 변수가 함수 범위를 벗어나면 자동으로 사라지는 이유
- 지 변수나 함수 호출 정보가 스택 메모리에 저장된다.

<br/>

#### **힙 메모리 (Heap)**
- 마구잡이로 쌓인 채 공중을 떠다니는 더미 형태
- 힙 메모리에 저장되는 데이터들은 사용자가 저장되는 위치를 제어할 수 없다.
- 동적으로 생성되는 객체는 힙 메모리에 저장된다.
- 개발자가 수동으로 메모리 할당, 해제를 해주어야 하며 속도가 상대적으로 느리다.
- C++에서는 new, delete 키워드를 사용해 힙 메모리를 할당하고 해제한다.
	- C#에서는 delete를 따로 하지 않아도 가비지 콜렉터가 자동으로 사용하지 않는 메모리를 해제한다.
	- GC가 너무 많으면 렉이 걸릴 수 있으니 적절히 처리해주어야 한다.

### **8. 데일리 과제**

```cpp
#include <iostream>
#include <string>

using namespace std;

int score = 0;

// 마법 주문 별 점수를 계산하는 함수
int CalculateScore(string magic)
{
	int extraScore = magic.length();

	return extraScore;
}

// 주문 성공 여부를 판단하는 함수
bool TextMagicAbility(string correct)
{
	cout << correct << " 주문을 입력하세요.\n";

	string userInput;
	// cin >> userInput;	"cin >> "은 공백 직전까지 입력 받음
	getline(cin, userInput);	// #include <string>

	if (correct == userInput)
	{
		score += CalculateScore(correct);
	
		return true;
	}

	return false;
}

// 기숙사 배정 함수
string AssignDorm(int total)
{
	string dormitory = "";

	if (total >= 60)
	{
		dormitory = "레번클로";
	}
	else if (total >= 45)
	{
		dormitory = "슬리데린";
	}
	else if (total >= 30)
	{
		dormitory = "그리핀도르";
	}
	else
	{
		dormitory = "후플푸프";
	}

	return dormitory;
}

int main()
{
	string magicArr[6] = {"Avada Kedavra", "Wingardium Leviosa", "Lumos", "Aquamenti", "Expelliarmus", "Stupefy"};

	for (int i = 0; i < 6; i++)
	{
		if (!TextMagicAbility(magicArr[i]))
		{
			cout << "점수를 얻지 못했습니다.\n";
		}
		else
		{
			cout << "주문에 성공했습니다.\n";
		}

		cout << "\n";
	}

	cout << "당신은 " << AssignDorm(score) << "에 배정되었습니다.\n";

	return 0;
}
```
