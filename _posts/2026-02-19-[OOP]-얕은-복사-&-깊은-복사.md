## 얕은 복사 & 깊은 복사

### **1. 얕은 복사 (Shallow Copy)**

#### **의미**
객체의 값을 복사할 때, 그 객체가 포인터나 참조라면 대상을 직접 복사하지 않고 주소만 복사하는 것을 의미한다.

```
- 객체를 하나 더 만들지 않고 포인터만 복사한다.
- 원래 객체의 주소를 가리킨다.
```

#### **결과**
- 원본과 복사본이 같은 데이터를 공유한다.
- 한쪽에서 데이터를 수정하면 다른 쪽 데이터도 바뀐다.
- 삭제 시 이중 해제 등의 문제가 발생할 수 있다.

### **2. 깊은 복사 (Deep Copy)**
#### **의미**
객체의 값을 복사할 때, 완전히 독립적인 객체를 만드는 것을 의미한다.

```
- 새로운 메모리를 할당한다.
- 그 안의 실제 데이터 내용을 똑같이 복사한다.
```

#### **결과**
- 원본과 복사본이 서로 영향을 미치지 않는다.
- 각자 안전하게 해제가 가능하다.
- 시간, 메모리 등의 비용이 더 많이 든다.

<br/>

-----------------

<br/>

### **3. 발생 가능한 문제**
#### **이중 해제**
- 얕은 복사로 같은 포인터를 공유한다.
- 두 객체를 모두 delete한다.
- 이미 해제한 메모리를 또 해제하게 된다.

#### **해제 후 사용**
- 한 객체가 먼저 delete된다.
- 이후 다른 객체가 이미 해제된 메모리를 계속 사용한다.

<br/>

-----------------

### **기본 동작**
#### **C++**
- 일반 멤버 변수에서는 값이 그대로 복사된다.
- 포인터 멤버 변수에서는 얕은 복사가 발생하게 된다.
- 동적 메모리를 사용하는 경우 깊은 복사를 원한다면 복사 생성자를 직접 만들어줘야 한다.

#### **C#**
-   class는 기본적으로 참조 공유이다.
-   struct는 값 복사가 발생한다.
-   GC로 메모리 안전하지만 참조 공유 문제가 존재한다.
