## [OZ 게임개발캠프] 17일차 (4 / 10)

### **1. 외래키 (Foreign Key)**
- 참조하려는 다른 테이블의 데이터 ID
- 다른 테이블의 기본키 (Primary Key)를 가져와 테이블끼리 연결시킨다. (관계형 데이터)

<br/>

-----------------

<br/>

### **2. 싱글톤 (Singleton)**
- **정적 클래스 (Static)** : 실체화 없이 접근 가능한 클래스
- **싱글톤 패턴** : 1개의 객체만 실체화하여 중복 생성을 방지하고 전역적인 접근이 가능하도록 만드는 패턴
	- 보통 데이터 매니저는 이 패턴을 사용한다.

<br/>

-----------------

<br/>

### **3. 데이터 형식**
- **JSON** : 키와 값으로 이루어져 있다.
	- 가볍기 때문에 데이터 송수신에 유리하다.
	- 명확한 데이터 타입이 있고 가독성이 좋다.

<br/>

- **XML** : <Tag>기반의 구조이며 유연한 스키마를 사용할 수 있다.
	- 속성을 통해 메타데이터를 제공할 수 있다.
