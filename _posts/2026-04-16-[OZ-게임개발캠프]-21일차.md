### **2. 의존성**
- 의존성이 높아지면 관련 기능들은 매니저 클래스로 몰아준다. (중앙 관제탑과 같은 역할)
	- 의존성이 사라지는 것은 아니라 위험한 방법이지만 잘 사용하면 좋다. (의존성 주입 방식)
- 몰라도 동작할 수 있도록 구조를 설계해야 한다.
- 능동태가 아닌 수동태 형식으로 코드를 짜야한다.
- 강한 의존성 : 스파게티 코드
- **느슨한 결합** : 두 객체 사이의 이벤트가 많을 경우에는 느슨한 결합이 맞는지 생각해봐야 한다.

### **3. 콜백 구조**
- 콜백은 한정적으로, 꼭 필요한 상황에 사용하는 것이 좋다.
- 보통 다른 클래스 객체에 무언가를 전달할 경우 사용한다. 
- 콜백은 남용하면 안되고 호출하고 응답을 받을 때까지 대기해야 하는 경우에 사용해야 한다.
	- 비동기 처리, 네트워크 처리에 주로 사용된다.
- 이벤트를 사용할 때 구독 대신 매개변수로 전달받는 바인드 메서드를 만들어주는 것이 좋다.

### **5. 데일리 과제**

```csharp
using System;

namespace DailyAssignmentCSharp
{
    internal class Event2
    {
        public class User
        {
            public string Name {  get; set; }

            public event Action OnEat;

            public void EatFood()
            {
                Console.WriteLine($"{this.Name}은(는) 음식을 열심히 먹기 시작합니다.");
            }

            public void Pray()
            {
                Console.WriteLine($"{this.Name}은(는) 기도를 합니다.");
                OnEat += EatFood;

                OnEat?.Invoke();
            }
        }

        public class Oven
        {
            public int Minute {  get; set; }
            public int Current { get; set; }

            public void OnCompleteFood(Action onEat)
            {
                Console.WriteLine("음식이 완성되었습니다.");
                onEat?.Invoke();
            }
        }

        static void Main(string[] args)
        {
            User user = new User();
            user.Name = "에헤헤";

            Oven oven = new Oven();
            oven.Minute = 50;
            oven.Current = 0;

            Console.WriteLine("1 입력 시 10분이 지나갑니다.");

            while (true)
            {
                int userInput = int.Parse(Console.ReadLine());

                if (userInput == 1)
                {
                    oven.Current += 10;

                    Console.WriteLine($"{oven.Current}분이 지났습니다.");
                }
                else
                {
                    Console.WriteLine("다시 입력해주세요.");
                }

                if (oven.Current >= 50)
                {
                    oven.OnCompleteFood(user.Pray);
                    break;
                }
            }
        }
    }
}
```
