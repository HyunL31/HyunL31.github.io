## [OZ 게임개발캠프] 8일차 (3 / 30)

### **1. Static 함수**
- 클래스에 속하며 객체 없이 호출 가능한 함수
- 캡슐화와 이름 충돌 방지가 가능하다.

```csharp
static void method() {}
```

```csharp
using System;

namespace OZCodingCsharp
{
    internal class Program      // 접근 제한자
    {
        static int _globalCoffeePrice;

        static void Main(string[] args)
        {
            int coffeePrice = 0;

            Console.WriteLine(coffeePrice);     // 지역변수는 초기화한 뒤 사용해야 한다.
            Console.WriteLine(_globalCoffeePrice);      // 멤버 변수는 괜찮다.

            float naftaWeight = 5.5f;
            Console.WriteLine(naftaWeight);
        }
    }
}

```

### **2. C#의 메모리**
- int와 같은 기본 자료형: 스택 메모리에 저장
- String: 힙 메모리에 저장
- 어디에 저장되는지 알고 있어서 GC를 줄이는 등 최적화를 할 수 있다.

### **3. C#의 String**
- 문자열 연산이 많을 경우 GC 부담이 커진다.
- C++에서 string은 기본으로 제공되는 자료형이 아니었지만 C#에서는 기본 자료형으로 취급된다.
- C#에서 String은 참조 타입이다.
- String은 불변 객체이기에 문자 추가나 수정 시 새로운 객체를 하나 더 만든다.
	- 따라서 메모리 사용량이 증가하기 때문에 while(), Update()에서는 사용하지 않는 것이 좋다.
	- 정 써야할 경우 3초에 한 번 등 타이머를 사용한다.

```csharp
// 문자열 format
string characterLevel = 10;
string result = $"Level {characterLevel}입니다.";

Console.WriteLine(result);
```

### **3. C#의 StringBuilder**
- 문자열의 성능을 높이기 위해 사용한다.
- 문자열 수정 시 내부적으로 새 객체를 만드는 것이 아니라 ToString()으로 문자열화만 한다.
- C#에서의 모든 객체는 ToString()이 가능하다.
- StringBuilder는 성능은 좋지만 코드가 복잡해져 최적화가 필요한 부분 외에는 잘 사용하지 않는다.

```csharp
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World");

string result = sb.ToString();
Console.WriteLine(result);
```

### **4. 그 외 기본 자료형 & 연산자**
- **unsigned** : 부호를 붙일 수 없는 자료형이다. 따라서 음수를 표현할 수 없다.
	- `uint` 등 자료형 앞에 `u`를 붙여서 사용할 수도 있다.
- **byte** : enum 최적화 등을 위해 byte 자료형을 사용한다. (255개 이하일 경우)

<br/>

- 나눗셈 연산자보다 곱셈 연산자가 더 빠르다. (`a / 2` 대신 `a * 0.5` 사용)

### **5. 형 변환**
```csharp
float characterHP = 95.7f;
int displayHP = (int)characterHP;

Console.WriteLine(displayHP);	// 95 출력

int a = 100;
int b = 200;
float result1 = a / b;		// (정수 / 정수)는 0이 된다.
float result2 = (float)a / b;		// 두 변수 중 하나를 형 변환 시켜줘야 한다.
float result3 = (float)(a / b);	// 연산의 결과 0을 float으로 형 변환했기에 0이 그대로 나옴
```

- 기본 자료형(값 타입)끼리의 형 변환은 비용이 비교적 크지 않아 괜찮다.
- 다만 참조 타입끼리의 형 변환은 주의가 필요하다. (`박싱`, `언박싱`)

### **6. 데일리 과제**

```cpp
using System;

namespace DailyAssignmentCSharp
{
    internal class Calculator
    {
        static int Plus(int first, int second)
        {
            int plusResult = first + second;

            return plusResult;
        }

        static int Minus(int first, int second)
        {
            int minusResult = first - second;

            return minusResult;
        }

        static int Multiply(int first, int second)
        {
            int multipliedResult = first * second;

            return multipliedResult;
        }

        static int Divide(int first, int second)
        {
            int divideResult = 0;

            try
            {
                divideResult = first / second;
            }
            catch (DivideByZeroException ex)
            {
                Console.WriteLine("0으로 나눌 수 없습니다.");
            }

            return divideResult;
        }

        static int Mod(int first, int second)
        {
            int modResult = 0;

            try
            {
                modResult = first % second;
            }
            catch (DivideByZeroException ex)
            {
                Console.WriteLine("0으로 나눌 수 없습니다.");
            }

            return modResult;
        }

        static int Square(int first, int second)
        {
            int squareResult = 1;

            for (int i = 0; i < second; i++)
            {
                squareResult *= first;
            }

            return squareResult;
        }

        static void Everything(int first, int second)
        {
            Console.WriteLine($"{first} + {second} = {Plus(first, second)}");
            Console.WriteLine($"{first} - {second} = {Minus(first, second)}");
            Console.WriteLine($"{first} * {second} = {Multiply(first, second)}");
            Console.WriteLine($"{first} / {second} = {Divide(first, second)}");
            Console.WriteLine($"{first} % {second} = {Mod(first, second)}");
            Console.WriteLine($"{first} ^ {second} = {Square(first, second)}");
        }

        static void Main(string[] args)
        {
            Console.WriteLine("두 수를 입력받아 계산하는 \"계산기\"입니다.\n");

            Console.WriteLine("원하는 연산의 숫자 중 하나를 골라 입력해주세요.");
            Console.WriteLine("1. +\n2. -\n3. *\n4. /\n5.%\n6. 제곱\n7. 위의 모든 연산\n");
            int expression = int.Parse(Console.ReadLine());

            Console.WriteLine("연산할 두 수를 하나씩 입력해주세요.");
            
            Console.Write("첫 번째 수: ");
            int firstNum = int.Parse(Console.ReadLine());

            Console.WriteLine();

            Console.Write("두 번째 수: ");
            int secondNum = int.Parse(Console.ReadLine());

            Console.WriteLine("연산 결과를 출력합니다.\n");

            switch (expression)
            {
                case 1:
                    Console.WriteLine($"{firstNum} + {secondNum} = {Plus(firstNum, secondNum)}");
                    break;

                case 2:
                    Console.WriteLine($"{firstNum} - {secondNum} = {Minus(firstNum, secondNum)}");
                    break;

                case 3:
                    Console.WriteLine($"{firstNum} * {secondNum} = {Multiply(firstNum, secondNum)}");
                    break;

                case 4:;
                    Console.WriteLine($"{firstNum} / {secondNum} = {Divide(firstNum, secondNum)}");
                    break;

                case 5:
                    Console.WriteLine($"{firstNum} % {secondNum} = {Mod(firstNum, secondNum)}");
                    break;

                case 6:
                    Console.WriteLine($"{firstNum} ^ {secondNum} = {Square(firstNum, secondNum)}");
                    break;

                case 7:
                    Everything(firstNum, secondNum);
                    break;
            }

            Console.ReadLine();
        }
    }
}
```
