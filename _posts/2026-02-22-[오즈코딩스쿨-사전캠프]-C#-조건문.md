## 사전캠프 - C# 조건문

### **1. 조건문**
**조건문**이란 컴퓨터에게 판단의 기준과 그에 따라 해야하는 연산을 알려주는 문법이다.

<br/>

-----------------

<br/>

### **2. C# 조건문의 종류**

#### **if / else if / else**
- 가장 기본적인 조건문이다.
- 조건이 다양하거나 복잡할 때 사용한다.
```csharp
if (age >= 65)
{
	Console.WriteLine("노년");
}
else if (age >= 20)
{
	Console.WriteLine("성인");
}
else
{
	Console.WriteLine("청소년");
}
```

#### **switch**
- 값이 정해져 있는 경우에 사용한다.
- 다수의 조건을 비교할 때 간결하게 사용한다.
```csharp
switch(메뉴)
{
	case 1:
		Console.WriteLine("김치찌개");
		break;
	case 2:
		Console.WriteLine("된장찌개");
		break;
	default:
		Console.WriteLine("공깃밥");
		break;
}
```

#### **삼항 연산자**
- 간단한 if-else를 한 줄로 표현할 때 사용한다.
```csharp
string result = (age >= 18) ? "성인" : "미성년자";
```

### **3. 과제**
```csharp
namespace OZcoding
{
    internal class Program
    {
        static void Main(string[] args)
        {
            int age = 21;
            bool hasCoupon = true;

            if (age >= 20 || hasCoupon)
            {
                Console.WriteLine("입장 가능합니다.");
            }
            else
            {
                Console.WriteLine("입장 불가입니다.");
            }
        }
    }
}
```
