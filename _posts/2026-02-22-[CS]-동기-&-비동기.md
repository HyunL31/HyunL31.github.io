## 동기 & 비동기

### **1. 동기 (Synchronous)**
**동기**란 어떤 한 작업이 끝날 때까지 다음 작업이 시작되지 않는 방식을 의미한다.
다음 작업으로 넘어가기 위해서는 현재 진행 중인 작업이 모두 끝나야 한다.

#### **특징**
- 순서가 보장되며 이해하기 쉽다.
- 느리고 중간에 멈출 가능성이 있다.
- UI가 멈출 가능성이 있다.

<br/>

-----------------

<br/>

### **2. 비동기 (Asynchronous)**
**비동기**란 작업 시작 후 진행하는 동안 다른 작업을 동시에 진행하는 방식을 의미한다.
다만 비동기는 동시에 진행되도록 설계되었을 뿐 멀티스레드처럼 꼭 다른 스레드를 사용해야하는 것은 아니다.

#### **특징**
- 순서가 보장되지 않으며 복잡하다.
- 효율적이고 중간에 멈출 가능성이 적다.

<br/>

-----------------

<br/>

### **3. 예시**
```csharp
// 동기
Console.WriteLine("1번 시작");
Thread.Sleep(3000); // 3초 멈춤
Console.WriteLine("2번 실행");

// 비동기
Console.WriteLine("1번 시작");  
  
Task.Delay(3000).ContinueWith(_  =>  
{  
	Console.WriteLine("2번 실행");  
});  
  
Console.WriteLine("3번 실행");
```
