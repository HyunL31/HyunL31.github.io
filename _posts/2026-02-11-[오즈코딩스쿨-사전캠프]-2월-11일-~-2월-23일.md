## 워밍업 - 뇌 가소성 (2 / 11)

오즈코딩스쿨 첫 사전캠프로 뇌 가소성에 대한 영상을 보게 되었다.

### **1. 뇌 가소성이란?**
**뇌 가소성**이란 인간의 뇌는 변화하는 환경에 적응하기 위해 끊임없이 변화하는 성질을 가지고 있다는 이론이다.

<br/>

-----------------

<br/>

### **2. 느낀 점**
편입 후 개발자가 되기 위해 나름 열심히 공부했다고 생각했지만 그게 아니었던 것 같다.
가끔 편입을 하지 않고 더 어릴 때부터 말랑말랑한 뇌를 가지고 개발 공부를 시작했다면 더 쉽지 않았을까~ 하는 생각을 한다.
물론 초등학생 때부터 개발을 배웠다면 달랐겠지만 영상을 보고 나니 20살이나 26살이나 거기서 거기 같기도 하고...
그냥 공부 안 하고 지피티에 의존만 하는 나 자신에 대한 자기합리화 아닌가 싶기도 하다... 반성...

뇌 가소성에서 중요한 것은 ```환경```과 ```내재적 동기```라고 한다.
환경은 항상 갖춰져 있었지만 문제는 내재적 동기인 것 같다.
영어 공부도, 개발 공부도 그냥 막연히 "취업 해야지!" 라는 생각으로 어영부영 해왔다.
이제부터라도 제대로 된 목표를 세워봐야겠다.

<br/>

-----------------

<br/>

### **3. 나의 목표**
월요일에 첫 회사 면접을 보고 왔다.
```10년 후 어떤 개발자가 되고 싶나요?```라는 질문에 제대로 된 답을 하지 못했다.
그냥 단순히 게임이 좋고 개발자는 돈도 많이 번다길래 시작했는데... 뭔 말을 해...

우선 교육이 끝나는 6개월 뒤 목표부터 세워보자.
- 백준 골드 문제 스스로 풀기
- AI 없이 혼자 게임 완성하기
- 내가 참여한 게임 출시하기
- 취업하기

열심히 해야겟다.

## 워밍업 - 아토믹 해빗 (2 / 13)

### **1. 아토믹 해빗이란?**
**아토믹 해빗**이란 작은 습관의 변화가 큰 힘을 가지고 있다는 내용의 책이다.

<br/>

-----------------

<br/>

### **2. 아토믹 해빗의 내용**
#### 습관 형성의 초점
- **결과** : 사람들은 대부분 습관을 형성한 뒤의 결과에만 집중한다.
- **과정** : 하지만 과정을 습관으로 만들면 결과는 저절로 따라온다. 
- **정체성** : 궁극적으로 자신의 정체성을 바꿔야 원하는 습관을 형성할 수 있다.

#### 행동의 마찰
좋은 행동을 습관으로 만들기 위해서는 그 행동이 아주 쉽게 느껴지도록 **마찰**을 줄여야 한다.
예를 들어 책을 읽는 습관을 만들기 위해서는 언제나 쉽게 읽을 수 있도록 책을 가까이에 두어야 한다.
반대로 나쁜 습관을 없애기 위해서는 행동의 마찰을 높여주면 된다.
일어나자마자 핸드폰하는 것을 방지하기 위해 침대에서 떨어진 곳에 핸드폰을 두는 것이 그 예시이다.

<br/>

-----------------

<br/>

### **3. 느낀 점**
어떻게 보면 당연한 이야기지만 새롭게 느껴졌던 이야기들이었다.
무엇보다 정체성을 바꿔야 한다는 부분이 흥미로웠다.
결과를 바꾸기 위해 과정을 바꾸고, 과정을 바꾸기 위해 정체성을 바꾸는...

취업 준비를 하는 동안 가질 나의 정체성을 생각해봤다.
- 문제를 해결하는 것을 좋아하는 사람
- 다양한 장르의 게임을 좋아하는 사람
- 게임 만드는 것을 좋아하는 사람

쉽지 않네...  

## 사전 캠프 - 게임이 만들어지는 과정 (2 / 16)

### **1. 내가 상상하는 게임의 아이디어**
최근 사주와 타로 카드에 꽂혔다.
하루에 한 번 ```오늘의 운세```나 ```타로 카드```를 랜덤으로 뽑아 그 결과가 게임에 영향을 미치는 게임을 제작해보고 싶다.
타로 카드의 종류에 따라 새로운 이벤트가 발생하도록 구성하고 싶다.

아침에 운세를 보고 간단한 조작을 한 뒤, 학교나 회사 등 일상에서는 크게 신경을 쓰지 않아도 되는 방치형 게임으로 구성하면 재미있을 것 같다.

<br/>

-----------------

<br/>

### **2. 게임의 핵심 재미 요소**
- 사주나 타로 카드는 오컬트적인 분위기가 특징이라고 생각한다. 그래서 그 분위기를 잘 살릴 수 있는 배경 및 카드 등의 아트가 중요할 것 같다.

- 사주나 타로는 랜덤 요소가 강하기 때문에 보드 게임에서의 주사위처럼 이야기의 흐름을 바꾸는 변수로 작용한다. 그래서 매일 어떤 결과가 나올지 모른다는 점에서 같은 게임이라도 조금씩 다른 플레이를 경험할 수 있어서 재미있을 것 같다.

## 사전캠프 - C#이란? (2 / 19)

### **1. C#이란?**
**C#**이란 마이크로소프트사에서 2000에 발표한 객체지향 언어이다.

#### **객체지향이란?**
```
데이터를 객체 단위로 묶어 프로그램을 구성하는 방식이다.
자동차를 만드는 것처럼 필요한 부품을 모으고 조립해 프로그램을 만드는 방식을 의미한다.
```

<br/>

-----------------

<br/>

### **2. C#의 특징**
- **강력한 타입 시스템**
	- 변수의 자료형을 미리 선언하기 때문에 컴파일 타임에 오류를 찾을 수 있다.
	- 장점: 프로그램 실행 전 오류를 미리 찾아낼 수 있다.
	- 단점: 변수의 선언이 조금 더 번거로워진다.

<br/>

- **자동 메모리 관리**
	- 가비지 컬렉션 (Garbage Collection)을 통해 메모리를 자동으로 해제한다.
	- free() 등의 메모리 해제를 직접 하지 않아 메모리 누수를 방지할 수 있다.

<br/>

- **.NET 플랫폼**
	- CPU, 운영체제마다 사용하는 기계어가 다르다.
	- C++의 경우 코드를 컴파일하면 바로 실행 가능한 기계어로 변환된다.
		- 따라서 실행하려는 CPU, 운영체제에 맞게 **크로스 컴파일**을 해주어야 한다.
	- C#의 경우 중간 언어 (IL)로 컴파일 된 뒤 **JIT**으로 CPU가 이해 가능한 기계어로 변환된다.
		- 따라서 다양한 플랫폼에서 사용 가능한 프로그램을 만들 수 있다.

<br/>

- **풍부한 라이브러리와 생태계**
	- C# 프로그램은 사물 인터넷 (IoT) 기기부터 클라우드까지 다양한 환경에서 사용 가능하다.
	- 웹 (ASP.NET), 데스크탑, 모바일, 게임 등 다양한 분야에서 활용 가능하다.

<br/>

## 사전캠프 - C# 변수와 데이터 타입 (2 / 20)

### **1. 변수**
**변수**란 데이터를 담을 수 있는 상자와 같다.
원하는 데이터를 변수 안에 담아놓고 사용할 수 있다.

#### **변수 선언 규칙**
변수를 선언하기 위해서는 규칙을 지켜야 한다.

```csharp
// 규칙
데이터타입 변수이름 = 값;

// 예시
string name = "aaa";
int num = 3;
bool isStudent = true;
```

<br/>

-----------------

<br/>

### **2. 데이터 타입**
**데이터 타입**은 그 변수에 어떤 타입의 데이터가 들어가야 하는지 컴퓨터가 알 수 있도록 명시해준다.
데이터 타입과 다른 값이 변수 안에 들어가면 컴파일 단계에서 오류가 발생할 수 있다.

#### **데이타 타입 예시**
| 분류 | 데이터 타입 | 설명 | 
|------|-------------|------|
| 숫자 | `int` | 정수 (소수점 없음) | 10, -5, 0 | 
| 숫자 | `long` | 아주 큰 정수 | 922337203685 | 
| 숫자 | `float` | 소수점 있는 숫자 (4바이트) |
| 숫자 | `double` | 더 정밀한 소수 (8바이트) |
| 숫자 | `decimal` | 초정밀 소수 (돈 계산용) |
| 논리 | `bool` | 참/거짓 |
| 문자 | `char` | 문자 1개 | 
| 문자열 | `string` | 글자들의 모음 |
| 날짜/시간 | `DateTime` | 날짜 + 시간 |
| 없음 | `null` | 값이 없음 (비어 있음) | 
| 기타 | `object` | 모든 타입의 부모 (다 담을 수 있음) |

<br/>

-----------------

<br/>

### **3. 과제**
```
“포도”라는 데이터를 “과일”이라는 변수에 담아 보세요!(데이터 타입 작성 필요)
```

#### **결과**
```csharp
namespace OZcoding
{
    internal class Program
    {
        static void Main(string[] args)
        {
            string 과일 = "포도";

            Console.Write(과일);
        }
    }
}
```

## 사전캠프 - C# 연산자 (2 / 21)

### **1. 연산자**
**연산자**란 값과 값 사이에서 무언가를 계산하거나 판단하게 도와주는 기호를 의미한다.
수학에서의 ```+```, ```-```, ```*```, ```%``` 등이 그 예시이다.

#### **예시**
```csharp
int age = 20;

if (age >= 18)	// 연산자를 활용한 비교
{
	Console.WriteLine("성인입니다.");
}
```

<br/>

-----------------

<br/>

### **2. 연산자의 종류**

#### **산술 연산자**
사칙연산 등 숫자를 계산할 때 사용하는 연산자이다.

| 연산자 | 의미 |
|--------|----------|
| + | 더하기 |
| - | 빼기 |
| * | 곱하기 |
| / | 나누기 |
| % | 나머지 |

#### **비교 연산자**
양쪽 값을 비교해 참과 거짓을 판단할 때 사용하는 연산자이다.

| 연산자 | 의미 |
|--------|----------------|
| == | 같다 |
| != | 같지 않다 |
| > | 크다 |
| < | 작다 |
| >= | 크거나 같다 |
| <= | 작거나 같다 |

#### **논리 연산자**
어떤 조건들을 연결할 때, 동시에 비교할 때 사용하는 연산자이다.

| 연산자 | 의미 |  
|--------|-----------------|  
| && | 그리고 (AND) |  
| \|\| | 또는 (OR) |  
| ! | 아니다 (NOT) |

## 사전캠프 - C# 조건문 (2 / 22)

### **1. 조건문**
**조건문**이란 컴퓨터에게 판단의 기준과 그에 따라 해야하는 연산을 알려주는 문법이다.

<br/>

-----------------

<br/>

### **2. C# 조건문의 종류**

#### **if / else if / else**
- 가장 기본적인 조건문이다.
- 조건이 다양하거나 복잡할 때 사용한다.
```csharp
if (age >= 65)
{
	Console.WriteLine("노년");
}
else if (age >= 20)
{
	Console.WriteLine("성인");
}
else
{
	Console.WriteLine("청소년");
}
```

#### **switch**
- 값이 정해져 있는 경우에 사용한다.
- 다수의 조건을 비교할 때 간결하게 사용한다.
```csharp
switch(메뉴)
{
	case 1:
		Console.WriteLine("김치찌개");
		break;
	case 2:
		Console.WriteLine("된장찌개");
		break;
	default:
		Console.WriteLine("공깃밥");
		break;
}
```

#### **삼항 연산자**
- 간단한 if-else를 한 줄로 표현할 때 사용한다.
```csharp
string result = (age >= 18) ? "성인" : "미성년자";
```

## 사전캠프 - C# 반복문 (2 / 23)

### **1. 반복문**
**반복문**이란 어떤 조건에 만족하는 동안 연산을 반복하도록 프로그래밍하는 문법이다.

<br/>

-----------------

<br/>

### **2. 반복문의 종류**
#### **for**
- 정해진 횟수만큼 반복한다.
- 반복해야 하는 횟수를 정확히 알고 있을 때 사용한다. 

```csharp
for (int i = 1; i <= 5; i++)
{
	Console.WriteLine($"{i}번째 출력입니다");
}
```

<br/>

#### **while**
- 어떤 조건이 참일 동안 계속 반복한다.
- 반복 조건이 있을 때 사용한다.

```csharp
int count = 0;

while (count < 3)
{
	Console.WriteLine("안녕하세요!");
	count++;
}
```

<br/>

#### **foreach**
- 여러가지 데이터 중 요소를 하나씩 꺼내어 반복한다.
- 배열, 리스트 등 컬렉션을 순회할 때 사용한다.

```csharp
string[] colors = { "빨강", "초록", "파랑" };

foreach (string color in colors) 
{
	Console.WriteLine(color);
}
```
