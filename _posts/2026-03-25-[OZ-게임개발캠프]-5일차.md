## [OZ 게임개발캠프] 5일차 (03 / 25)

### **1. 배열 (Array)**
- **배열** : 같은 종류의 데이터를 일렬로 묶어 관리하는 **고정된 크기**의 자료구조
- 인덱스로 관리하며 0부터 시작한다.
- 각 요소는 다른 주소값에 저장 (연속된 메모리에 저)
- 바둑, 슬롯, 지뢰찾기, 게임의 맵 등에서 이용된다.

#### **예시**
```cpp
int arr[5] = {1, 2, 3, 4, 5};

cout << arr[1];		// 2 출력
```

### **2. 다차원 배열**
- **다차원 배열** : 배열의 요소가 또 다른 배열로 이루어진 자료구조

#### **예시**
```cpp
int arr[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};

cout << arr[0][2];		// 3 출력
```

### **3. 지역 변수 & 전역 변수**
- **지역 변수 (Local Variable)** : 선언된 함수 안에서만 살아있는 변수
	- 함수가 시작될 때 메모리에 할당
	- 스택 영역에 저장

<br/>

- **전역 변수 (Global Variable)** : 함수 밖에 선언되어 프로그램이 종료될 때까지 살아있는 변수
	- 프로그램이 시작될 때 바로 메모리에 할당
	- 데이터 영역에 저장
	- 전역 변수 남용 시 스파게티 코드의 위험성이 있어 주의해야 한다.
		- 각 함수의 변수들이 체인처럼 연결된 형태가 더 안전하다.
	- 보통 전역적으로 선언된 변수는 구별을 위해 `_`, `m_` 등을 변수명 앞에 붙여준다.

### **5. 포인터 (Pointer)**
- **포인터** : 특정 메모리의 위치를 가리키는 특정 주소 (포인터도 특별한 자료형이다.)
- **포인터 변수** : 포인터를 담는 변수
	- 포인터 변수를 한 번 선언하면 주소만 바꾸어 다른 메모리에 접근할 수 있다.

#### **예시**
```cpp
int dog = 100;
int* dogPointer = &dog;		// 포인터 변수 (변수 dog의 주소값)

// 역참조
*dogPointer = 20;		// 변수 dog의 값이 20으로 바뀜

// 오류 발생
dogPointer = 20;		// 포인터 변수도 특정 자료형이라 할 수 있는데 정수형 데이터가 대입되었기에 오류 발생

// 배열
cout << arr;				// 0번째 배열의 주소
cout << arr + 1;		// 1번째 배열의 주소값
cout << *(arr + 1) << " " << arr[1];		// 둘 다 같은 1번째 배열의 값
```

### **6. 값 전달 & 참조 전달**
- **값 전달** : 변수를 복사하여 전달
- **참조 전달** : 변수의 주소값을 전달하여 원본에 접근 (반환 없이 변수의 값을 바꾸는 방법)

#### **예시**
```cpp
// 값 전달
void AddValue(int money)
{
	money += 100;
}

// 참조 전달
void AddReference(int& money)
{
	money += 100;
}

int main()
{
	int money = 50;

	AddValue(money);
	cout << money;	// 50 (값 전달이기에 복사본을 전달하여 원본에는 영향 X)

	AddReference(money);
	cout << money;	// 150 (변수의 원본에 접근하였기 때문에 값이 변경)
}
```

### **7. 동적 할당 (Dynamic Allocation)**
- **동적 할당** : 런타임에 메모리를 필요한 만큼 가져와서 사용하는 것
	- 동적 할당한 데이터는 힙 메모리에 저장된다.
	- 반대 개념은 **정적 할당**으로 스택 메모리에 저장된다.
	- C++에서는 동적 할당 후 직접 메모리 해제를 해줘야 하고 C#에서는 가비지 컬렉터가 자동으로 해제한다.
	- 그러나 GC가 많아지면 프레임 드랍 등이 발생하기에 오브젝트 풀링 등을 사용한다.
