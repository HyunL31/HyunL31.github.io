## 에라토스테네스의 체 (소수 판정 알고리즘)

### **1. 소수 (Prime)**
**소수 (Prime)**란 1과 자기 자신만을 약수로 갖는 자연수를 말한다.
백준에서 문제를 풀다보니 단순히 for문만으로 소수를 찾는 것이 비효율적이라 느꼈다.
무엇보다 자꾸 시간 초과가 나와 알고리즘을 한 번 찾아봤다.

### **2. $\sqrt n$까지 나눠보기**
#### **원리**
어떤 수 $n$이 소수인지 알아보려면 2부터 $\sqrt n$까지 나눠보면 된다.
약수는 곱해서 $n$이 되는 두 수이다. ($n = a \times b$)
두 수가 모두 $\sqrt n$보다 크다면 이미 곱은 $n$을 초과하기에 약수가 될 수 없다.
따라서 두 수 중 하나는 $\sqrt n$보다 작아야 한다.


이 방법은 하나의 수를 판정할 때 주로 사용한다.

<br/>

#### **예시**
```cpp
bool isPrime(int n)
{
	if (n < 2)
	{
		return false;
	}

	for (int i = 2; i * i <= n; i++)
	{
		if (n % i == 0)
		{
			return false;
		}
	}
	
	return true;
}
```

### **3. 에라토스테네스의 체**
#### **원리**
**에라토스테네스의 체**는 1부터 $n$까지의 모든 소수를 구하고 싶을 때 사용한다.
2부터 시작해 $\sqrt n$까지의 배수를 제거해나가는 방식이다.
전부 제거했을 때 남는 수들이 소수이다.

<br/>

#### **예시**
```cpp
vector<int> prime(int n)
{
	vector<bool> isPrime(n + 1, true);
	vector<int> primes;

	if (n >= 2)
	{
		primes.push_back(2);
	}
  
	for (int i = 3; i <= n; i += 2)
	{
		isPrime[i] = true;
	}

	for (int i = 3; i * i <= n; i += 2)
	{  
		if (isPrime[i])
		{  
			for (int j = i * i; j <= n; j += 2 * i)
			{  
				isPrime[j] = false;  
			}  
		}
	}
  
	for (int i = 3; i <= n; i += 2)
	{  
		if (isPrime[i])
		{
			primes.push_back(i);
		}
	}

	return  primes;  
}
```
