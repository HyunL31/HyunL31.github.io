## 트리 (Tree)

### 1. 트리 (Tree)
**트리**란 **계층 구조**를 표현하는 자료구조이다.
사이클이 없는 연결 그래프라고 표현하기도 한다.

<br/>

-----------------

<br/>

### **2. 트리의 용어**
![Desktop View](/assets/img/tree1.jpg){: w="700" h="400" }

<br/>

- Node (노드) : 트리를 이루는 점 (데이터)
- Edge (간선) : 노드와 노드를 연
- Root (루트) : 최상단 노드 (트리마다 딱 하나만 존재)
- Parent / Child (부모 / 자식) : 위, 아래로 직접 연결된 노드들
- Sibling (형제) : 같은 부모를 가진 노드들
- Leaf (리프) : 자식이 없는 노드들 (끝 노드)
- Subtree (서브트리) : 어떤 노드를 루트로 삼는 부분 트리
- Level (레벨) : 루트에서부터 몇 번째 층인지를 의미
- Depth (깊이) : 루트에서 해당 노드까지의 거리 (간선 수)
- Height (높이) : 해당 노드에서 가장 깊은 리프 노드까지의 거리 (간선 수)
- Degree (차수) : 노드가 가진 자식의 수

### **3. 트리의 종류**
1. **이진 트리 (Binary Tree)**
	- 모든 노드의 자식이 최대 2개 (LeftChild / RightChild)

2. **이진 탐색 트리 (Binary Search Tree, BST)**
	- **정렬 규칙**이 있는 트리
	- 보통 왼쪽 ```서브 트리 < 루트 < 오른쪽 서브트리``` 순으로 정렬된다.
	- 탐색, 삽입, 삭제 평균 시간복잡도는 $O(lon n)$이지만 편향된 경우 $O(n)$이 걸린다.

3. **균형 트리 (AVL, Red-Black)**
	- **AVL 트리**, **Red-Black 트리** 등은 이진 탐색 트리이지만 자체적으로 균형을 유지하는 균형 트리이다.
	- 이진 탐색 트리에서 한 쪽으로 편향되는 경우를 방지하기 위해 사용된다.
	- 따라서 시간 복잡도는 대부분 $O(log n)$이다.

4. **힙 (Heap)**
	- 부모와 자식 노드의 우선 순위에 따라 정렬된 트리
	- Max Heap과 Min Heap이 있다.
	- 보통 완전 이진 트리와 배열로 구현된다.

6. **트라이 (Trie)**
	- 문자열 검색용 트리
	- 자동 완성, 접두사 검색 등에 사용된다.

### **4. 트리 순회**
1. **Preorder (전위 순회)**
	- 부모 → 왼쪽 자식 → 오른쪽 자식 순으로 진행된다.
![Desktop View](/assets/img/tree2.jpg){: w="700" h="400" }

2. **Inorder (중위 순회)**
	- 왼쪽 자식 → 부모 → 오른쪽 자식 순으로 진행된다.
![Desktop View](/assets/img/tree3.jpg){: w="700" h="400" }

3. **Postorder (후위 순회)**
	- 왼쪽 자식 → 오른쪽 자식 → 부모 순으로 진행된다.
![Desktop View](/assets/img/tree4.jpg){: w="700" h="400" }

4. **Level-Order (레벨 순회)**
	- 루트부터 레벨 순으로 층층이 순회한다.
![Desktop View](/assets/img/tree5.jpg){: w="700" h="400" }
