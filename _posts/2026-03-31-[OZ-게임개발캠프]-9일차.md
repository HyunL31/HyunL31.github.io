## [OZ 게임개발캠프] 9일차 (3 / 31)

### **1. .Net 프레임워크 (닷넷)**
- C#은 코드가 바로 기계어가 되는 것이 아니라 IL(중간 언어)로 변환된 후 **가상 머신 (CLR)**이 **실시간**으로 번역한다.
- 이렇게 실시간으로 기계어로 번역해주는 가상머신을 포함한 것이 **닷넷 프레임워크**이다.

<br/>

-----------------

<br/>

### **2. namespace**
- **네임스페이스**란 클래스, 함수 등을 그룹으로 묶는 것으로 동일한 이름 충돌을 방지하기 위해 사용한다.
- C#에서는 C++에서 헤더파일을 사용하는 것처럼 네임스페이스를 사용해 다양한 함수 등을 가져올 수 있다.
- C++의 #include는 헤더파일을 복사하여 포함시키는 방식이다.
- C#의 using은 네임스페이스를 참조하는 방식이다.

<br/>

-----------------

<br/>

### **3. 값 타입 & 참조 타입**
- **값 타입** : 변수에 실제 값이 저장되며 선언 위치에 따라 스택 또는 힙에 저장된다.
	- C#에서 값 타입을 참조로 전달할 경우 `&` 대신 `ref` 키워드를 사용한다.
	- `out` 키워드를 사용할 경우 함수 내에 대입 연산이 있어야 한다.
- **참조 타입** : 변수에는 주소가 저장되고 실제 객체는 힙에 생성된다.

<br/>

-----------------

<br/>

### **4. readonly**
- **readonly**는 값을 한 번만 설정하고 이후에는 변경할 수 없게 만드는 상수화 키워드이다.
- 초기화는 가능하지만 이후 수정은 불가능하다. (생성자에서 초기화 가능)
- **const**처럼 멤버 변수에서만 사용 가능하다.
- **const**와 달리 초기값이 **런타임**에 설정된다.

<br/>

-----------------

<br/>

### **5. Enum**
- Enum에서 항상 첫 번째는 **None**을 넣어주는 것이 좋다. (디폴트 처리가 편하다.)
- 사용 시점에 메모리 할당
- 255개 미만일 경우에는 byte를 주로 사용한다.
