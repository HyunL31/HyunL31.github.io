## [OZ 게임개발캠프] 16일차 (4 / 9)

### **1. 알고리즘**
- 아무리 **선형 시간**이어도 **Update()**에서 사용되는 로직은 조심해야 한다.
- 복잡한 로직도 가독성, 확장성이 좋고 다른 프로그래머에게 설명하지 않아도 될 정도로 정리가 잘 되어 있으며 매 프레임마다 불려지는 게 아니라면 괜찮은 알고리즘이다.

### **2. 정렬 알고리즘**
- **삽입 정렬** : 앞의 데이터와 비교해 적은 값을 찾아낼 때까지 뒤로 밀어낸다. 두 번째 데이터부터 시작한다.
- **버블 정렬** : 인접 데이터와 비교하며 정렬한다. 맨 뒤에서부터 정렬이 된다.
- **선택 정렬** : 최소값이 찾아 순차적으로 정렬한다.
- **퀵 정렬** : 기준점을 잡고 작으면 왼쪽, 크면 오른쪽으로 보내는 것을 반복한다.
- **병합 정렬** : 리스트를 절반으로 자르는 것을 반복하고 정렬하며 합치는 것을 반복한다. (재귀)

#### **예시**
```csharp
// 삽입 정렬
static void InsertionSort(int[] arr)
{
	for (int i = 1; i < arr.Length; i++)
	{
		int key = arr[i];
		int j = i - 1;

		while (j >= 0 && arr[j] > key)
		{
			arr[j + 1] = arr[j];
			j--;
		}

		arr[j + 1] = key;
	}
}

// 버블 정렬
static void BubbleSort(int[] arr)
{
	for (int i = 0; i < arr.Length - 1; i++)
	{
		for (int j = 0; j < arr.Length - 1 - i; j++)
		{
			if (arr[j] > arr[j + 1])
			{
				int temp = arr[j];
				arr[j] = arr[j + 1];
				arr[j + 1] = temp;
			}
		}
	}
}

// 선택 정렬
static void SelectionSort(int[] arr)
{
		for (int i = 0; i < arr.Length - 1; i++)
		{
			int minIdx = i;

			for (int j = i + 1; j < arr.Length; j++)
			{
				if (arr[j] < arr[minIdx])
				{
					minIdx = j;
				}
			}

			int temp = arr[i];
			arr[i] = arr[minIdx];
			arr[minIdx] = temp;
	}
}

// 퀵 정렬
static void QuickSort(int[] arr, int left, int right)
{
	if (left < right)
	{
		int pivot = Partition(arr, left, right);

		QuickSort(arr, left, pivot - 1);
		QuickSort(arr, pivot + 1, right);
	}
}

static int Partition(int[] arr, int left, int right)
{
	int pivot = arr[right];
	int idx = left - 1;

	for (int i = left; i < right; i++)
	{
		if (arr[i] < pivot)
		{
			idx++;

			int temp1 = arr[idx];
			arr[idx] = arr[i];
			arr[i] = temp1;
		}
	}

	int temp2 = arr[idx + 1];
	arr[idx + 1] = arr[right];
	arr[right] = temp2;

	return idx + 1;
}

// 병합 정렬
static void MergeSort(int[] arr, int left, int right)
{
	if (left < right)
	{
		int mid = (left + right) / 2;

		MergeSort(arr, left, mid - 1);
		MergeSort(arr, mid + 1, right);

		Merge(arr, left, mid, right);
	}
}

static void Merge(int[] arr, int left, int mid, int right)
{
	int[] temp = new int[right -  left + 1];
	
	int i = left;
	int j = mid + 1;
	int k = 0;

	while (i <= mid && j <= right)
	{
		 if (arr[i] <= arr[j])
		{
			temp[k++] = arr[i++];
		}
		else
		{
			temp[k++] = arr[j++];
		}
	}

	while (i <= mid)
	{
		temp[k++] = arr[i++];
	}

	while (j <= right)
	{
		temp[k++] = arr[j++];
	}

	for (int idx = 0; idx < temp.Length; idx++)
	{
		arr[left + idx] = temp[idx];
	}
}
```

### **3. 탐색 알고리즘**
- **이진 탐색 알고리즘** : 정렬된 데이터에서 특정 데이터의 위치를 찾는 알고리즘이다.
	- 중간값을 기준으로 찾고자 하는 데이터가 중간값보다 작을 경우에는 왼쪽으로, 클 경우에는 오른쪽으로 이동한다.

<br/>

- **순차 탐색 알고리즘** : 처음부터 끝까지 데이터를 순차적으로 탐색하며 원하는 데이터의 위치를 찾는 알고리즘이다.

### **4. 관계 분석 알고리즘 (그래프)**
- **BFS (너비 우선 탐색)** : 시작 노드로부터 가까운 이웃 노드들부터 방문하는 알고리즘이다.
- **DFS (깊이 우선 탐색)** : BFS와 반대로 한 방향으로 최대한 깊게 탐색하고 돌아오는 알고리즘이다.
- **최단 경로 알고리즘**
	- **다익스트라** : 시작 노드부터 다른 모든 노드까지의 최단 거리를 찾는 알고리즘이다.
	- **A* 알고리즘** : 다익스트라 알고리즘을 확장해 목적지까지의 거리를 예측하는 알고리즘이다.

### **5. 그 외 알고리즘**
- **백트래킹** : 막다른 곳에 부딪히면 다시 뒤로 돌아가 다른 길을 찾는 알고리즘이다.
- **다이나믹 프로그래밍** : 큰 문제를 작은 단위로 나누어 푼 뒤 결과를 저장해놓는 알고리즘이다.
- **그리디** : 매 순간 최선이라 생각하는 선택을 하는 알고리즘이다.
