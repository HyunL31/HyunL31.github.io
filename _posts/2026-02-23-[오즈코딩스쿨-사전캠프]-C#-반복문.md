## 사전캠프 - C# 반복문

### **1. 반복문**
**반복문**이란 어떤 조건에 만족하는 동안 연산을 반복하도록 프로그래밍하는 문법이다.

<br/>

-----------------

<br/>

### **2. 반복문의 종류**
#### **for**
- 정해진 횟수만큼 반복한다.
- 반복해야 하는 횟수를 정확히 알고 있을 때 사용한다. 

```csharp
for (int i = 1; i <= 5; i++)
{
	Console.WriteLine($"{i}번째 출력입니다");
}
```

<br/>

#### **while**
- 어떤 조건이 참일 동안 계속 반복한다.
- 반복 조건이 있을 때 사용한다.

```csharp
int count = 0;

while (count < 3)
{
	Console.WriteLine("안녕하세요!");
	count++;
}
```

<br/>

#### **foreach**
- 여러가지 데이터 중 요소를 하나씩 꺼내어 반복한다.
- 배열, 리스트 등 컬렉션을 순회할 때 사용한다.

```csharp
string[] colors = { "빨강", "초록", "파랑" };

foreach (string color in colors) 
{
	Console.WriteLine(color);
}
```

### **3. 과제**
```csharp
namespace OZcoding
{
    internal class Program
    {
        static void Main(string[] args)
        {
            for (int i = 0; i < 5; i++)
            {
                Console.WriteLine("안녕하세요!");
            }
        }
    }
}
```
