### **2. 유니티 시간**
- **Time.deltaTime** : 이전 프레임에서 다음 프레임까지 걸린 시간
	- float이기 때문에 == 연산자보다 <=, < 등의 연산자를 사용하는 것이 좋다.
	- 게임 로직은 프레임이 아닌 시간 단위로 처리한다.
	- 프레임이 높을수록 deltaTime은 작아진다.

<br/>

- **Time.timeScale** : 시간의 흐름을 관리할 수 있게 해준다.
	- 하지만 타임 스케일이 0이 되면 Update()는 멈추지 않고 FixedUpdate()는 멈춘다.
	- 따라서 타임 스케일보다는 연출의 영역에서 제어하는 것이 좋다.

### **3. 유니티 Transform**
- **Transform** : 모든 게임 오브젝트가 반드시 가지고 있는 컴포넌트 (2D는 **RectTransform**)
	- 모든 게임 오브젝트가 가지고 있다는 것은 다른 오브젝트에 transform으로 접근 가능하다는 것이다.
	- **SetParent**도 transform으로 접근할 수 있다.
	- 위치 (Position), 회전 (Rotate), 크기 (Scale)로 구성된다. (3개의 **Vector3**)
	- **World Position** : 게임 월드 그 자체를 기준으로 한 좌표
	- **Local Position** : 그 게임 오브젝트의 부모를 기준으로 한 좌표
		- 자식의 Local Scale은 가급적 (1, 1, 1)이 좋다. (대신 부모의 Scale을 바꾸자)

<br/>

- **transform.Traslate** : 게임 오브젝트가 순간적으로 이동한다.
	- 미세한 장애물은 그대로 넘어갈 수도 있으니 주의해야 한다.
```csharp
// 순간 이동
gameObject.transform.Translate(Vector3.up * 2, Space.World);

// 지속적 이동
gameObject.transform.Translate(Vector3.forward * Time.deltaTime, Space.Self);
```

<br/>

- **transform.LookAt** : 어떤 게임 오브젝트를 바라본다.
```csharp
gameObject.transform.LookAt(otherObject.transform);
```

<br/>

- **transform.Rotate** : 게임 오브젝트를 회전한다.
	- transform.Traslate와 마찬가지로 순간적 회전, 지속적 회전이 모두 가능하다.
```csharp
// 순간적 회전
gameObject.transform.Rotate(Vector3.up * 90f);

// 지속적 회전
gameObject.transform.Rotate(Vector3.up * Time.deltaTime * 30);
```

### **4. Rigidbody (리지드바디)**
- **Rigidbody** : 질량을 가진 물리적 객체를 만들기 위한 컴포넌트
	- **UseGravity** : 중력 여부
	- **Drag** : 공기 저항, 회전 저항 등의 마찰과 저항력
	- **충돌 반응** : **Collider**와 결합해 다른 오브젝트와의 충돌을 관리
	- **Is Kinematic** : 물리 무시, Is Kinematic 활성화 시 중력 등의 물리 법칙을 무시
	- **Interpolate** : 프레임 간의 이동을 부드럽게 보간
	- **Constraint** : 특정 방향으로의 이동, 회전 등을 의도적으로 제한할 때 사용

<br/>

- **LinearVelocity** : 속도 대입으로 가속, 정확한 컨트롤이 필요할 때 사용한다.
- **AddForce** : 힘 전달, 질량과 저항에 따라 결과가 다르다.
	- **ForceMode** : `Force (지속적인 힘)`, `Acceleration (지속적인 가속도)`, `Impulse (순간적인 충격량)`, `VelocityChange (순간적인 속도 변화)`
```csharp
// LinearVelocity
gameObject.linearVelocity = new Vector2(targetXVelocity, currentYVelocity);

// AddForce
gameObject.AddForce(Vector3.up * jumpPower, ForceMode.VelocityChange);
```

### **5. 충돌**
- **AABB 충돌** : Axis Aligned Bounding Box, 정렬된 축을 이용한 충돌 체크 알고리즘
	- 연산이 가볍고 빨라 유니티에서 1차 검사 용도로 사용된다.
	- 메쉬의 방향과 충돌 박스의 축이 일치하지 하지 않을 수 있다.
- **OBB 충돌** : Oriented Bounding Box, Bounding Box를 이용한 정밀한 충돌 체크 알고리즘
	- AABB보다 연산량이 많고 1차에서 걸러진 오브젝트들과의 충돌 체크에 사용된다.

<br/>

- **Collider** : 게임 오브젝트의 물리적인 형체를 정의하는 컴포넌트
	- 다른 오브젝트와의 충돌을 감지할 수 있게 해준다.
	- `Sphere` < `Capsule` < `Box` <<<< `Mesh` 순으로 콜라이더가 무거워진다.
	- `Box Collider`가 OBB 연산을 수행한다.
	- `Mesh Collider`는 매우 무겁기 때문에 지양하는 것이 좋다.

<br/>

- **Trigger** : 다른 오브젝트를 통과할 수 있으며 오로지 충돌을 감지하기만 한다.
- **Collision** : 물리적인 충돌을 감지하며 다른 오브젝트를 통과할 수 없다.
	- **Is Trigger** 체크 박스로 전환할 수 있다.

<br/>

- **Compound Collider** : **최적화**를 위해 하나의 Mesh Collider 대신 여러 개의 Sphere Collider를 사용하는 방법
	- 자식 오브젝트에 콜라이더가 많아도 반드시 Rigidbody는 부모 오브젝트에만 넣어야 한다.

### **6. Raycast**
- **Physics.Raycast** : 특정 방향으로 레이저를 쏘아 그 선과 충돌하는 물체가 있는지 체크한다.
	- 파라미터 : Origin (시작점), Dirction (방향), hit (정보를 담을 변수), MaxDistance (레이의 길이)

```csharp
RaycastHit hit;

if (Physics.Raycast(transform.position, transform.forward, out hit, _raycastDis))
{
	Debug.Log("레이캐스트와 충돌!!");

	// 충돌한 오브젝트 제거 가능
	Destroy(hit.collider.gameObject);
}
```

### **7. 데일리 과제**
```csharp
using UnityEngine;

public class PlayerMove : MonoBehaviour
{
    public float moveSpeed = 5.0f;
    public float jumpPower = 5.0f;
    public float collideDis = 30f;
    public float angle = 5f;

    private bool _isForward = true;
    private bool _isRight = false;

    private Rigidbody _rigidbody;

    private void Start()
    {
        _rigidbody = GetComponent<Rigidbody>();
    }

    void Update()
    {
        if (Input.GetKey(KeyCode.W))
        {
            _isForward = true;
            _isRight = false;

            Move();
        }
        else if (Input.GetKey(KeyCode.S))
        {
            _isForward = false;
            _isRight = false;

            Move();
        }
        else if (Input.GetKey(KeyCode.D))
        {
            _isForward = false;
            _isRight = true;

            Move();
        }
        else if (Input.GetKey(KeyCode.A))
        {
            _isForward = true;
            _isRight = true;

            Move();
        }

        if (Input.GetKey(KeyCode.Q))
        {
            Rotation(-angle);
        }
        else if (Input.GetKey(KeyCode.E))
        {
            Rotation(angle);
        }

        if (Input.GetKeyDown(KeyCode.Space))
        {
            Jump();
        }

        Shoot();
    }

    private void Move()
    {
        Vector3 dir = Vector3.forward;

        if (_isForward && !_isRight)
        {
            dir = Vector3.forward;
        }
        else if (!_isForward && !_isRight)
        {
            dir = Vector3.back;
        }
        else if (!_isForward && _isRight)
        {
            dir = Vector3.right;
        }
        else
        {
            dir = Vector3.left;
        }

        transform.Translate(dir * Time.deltaTime * moveSpeed);
    }

    private void Rotation(float angle)
    {
        transform.Rotate(Vector3.up * angle);
    }

    private void Jump()
    {
        _rigidbody.AddForce(Vector3.up * jumpPower, ForceMode.VelocityChange);
    }

    private void Shoot()
    {
        RaycastHit hit;

        if (Physics.Raycast(transform.position, transform.forward, out hit, collideDis))
        {
            Debug.Log($"몬스터 {hit.collider.gameObject.name}이(가) Ray에 맞았습니다!");

            Destroy(hit.collider.gameObject);
        }
    }
}

```
