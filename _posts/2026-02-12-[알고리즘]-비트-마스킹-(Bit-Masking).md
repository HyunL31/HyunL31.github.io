## 비트마스킹 (Bit Masking)

### **1. 비트마스킹이란?**
**Bit Masking**이란 정수의 각 비트를 이용해 여러 개의 상태를 저장하고 확인하는 기법이다.

#### 예시
```
// 어떤 숫자가 존재하는지 확인할 때
00000 = 어떤 값도 존재하지 않음
10101 = 1, 3, 5번 값 존재
```

### **2. 비트 마스킹 기본 연산**
```cpp
// 특정 비트 켜기
x |= (1 << i);		// i번째 비트 1로 만든다.
```

```cpp
// 특정 비트 끄기
x &= ~(1 << i);		// i번째 비트를 0으로 만든다.
```

```cpp
// 특정 비트 확인
if (x & (1 << i))		// i번째 비트가 1인지 확인
```

```cpp
// 특정 비트 토글
x ^= (1 << i);		// 1이면 0, 0이면 1로 바꾼다.
```

#### 예시
```cpp
int main()
{
    int x = 0;

    // 2번째 비트 켜기
    x |= (1 << 2);   // 0000 → 0100

    // 0번째 비트 켜기
    x |= (1 << 0);   // 0100 → 0101

    cout << x << endl;  // 5

    // 2번째 비트 확인
    if (x & (1 << 2))
    {
	    cout << "Yes" << endl;
    }
}
```

### **3. 비트 마스킹의 장단점**

#### 장점
- 메모리를 절약할 수 있다.
- 비트 연산은 CPU에서 빠르게 처리된다.
- 코드가 간결하다.

#### 단점
- 직관적이지 않다.
- 비트 수에 제한이 있다.
