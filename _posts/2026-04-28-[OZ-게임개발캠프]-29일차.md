## [OZ 게임개발캠프] 29일차 (4/28)

### **1. Get과 Find 함수의 차이**
- 찾는 시간에 따라 Get과 Find가 메서드 이름에 붙는다.
- for문을 사용하는 등 **선형 시간**에 찾는 경우 **Find**를 메서드 이름 앞에 붙인다.
- 반대의 경우에 **Get**을 붙인다.

### **2. util Class**
- static class이기에 this가 불가능하다.
- 반면 static class이기에 다른 컴포넌트에서 안전하게 부를 수 있다.
- 보통 수학, 레벨 및 경험치 계산 등에 이용되는 메서드들이 모여 있다.
- 어떤 아이템의 정보를 매핑하는 등에 이용된다.
- 인풋과 아웃풋, 즉 파라미터와 반환형이 확실한 경우 util 함수라고 한다.

<br/>

-----------------

<br/>

### **3. 레이아웃**
- UI를 제작할 때 부모 오브젝트로 위치를 먼저 잡아준다.
- 레이아웃 위치는 부모 오브젝트에서 **Anchor**와 **Stretch**를 사용해 해상도 대응을 해준다.
- UI를 나중에 한 번에 수정하기는 힘드니 미리미리 하이어라킹을 잘 해줘야 한다.
```
Lobby UI (얘를 프리팹으로 만든다.)
 ㄴ Layout_Top
	 ㄴ Skip Button
	 ㄴ Save Button
 ㄴ Layout_Left
	 ㄴ Quit Button
	 ㄴ EXP Text
```
