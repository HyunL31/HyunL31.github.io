## 포인터 & 참조

### **1. 포인터 (Pointer)**
**포인터**란 다른 변수의 주소를 저장하는 **변수**이다.

#### **예시**
```cpp
int  a = 10;
int* p = &a;

cout << p;  // 주소 출력  
cout << *p; // 10 출력
```
- `a` : 값이 10인 변수
- `&a` : 변수 a의 주소
- `p` : 변수 a의 주소를 저장하는 변수
- `*p` : 변수 p가 가리키는 주소의 값 (10)

<br/>

<br/>

#### **포인터의 특징**
- 주소값을 직접 다룬다.
- `nullptr``을 할당할 수 있다.
- 다른 주소를 가리키도록 변경할 수 있다.
- 동적 메모리 할당이 가능하다. (`new` / `delete`)

#### **포인터를 사용하는 경우**
- 트리, 그래프
- 동적 메모리
- null 사용이 필요할 때

#### **참조를 사용하는 경우**
- 함수 매개변수
- 복사를 방지할 때
- 값을 수정해야 할 때

### **2. 참조 (Reference)**
**참조**란 이미 존재하는 변수의 또 다른 이름이다.

#### **예시**
```cpp
int a = 10;  
int& r = a;

r = 20;  
cout << a; // 20
```
- `r` : 변수 a의 또 다른 이름
- 참조 r은 포인터와 달리 주소를 저장하지 않는다.
- 참조 r 자체가 변수 a이다.
- 참조 r의 값을 바꾸면 변수 a의 값도 바뀐다.

<br/>

#### **참조의 특징**
- 선언 시 반드시 초기화를 해야한다.
- 다른 대상을 가리키도록 변경할 수 없다.
- null이 불가능하다.

### **3. 함수에서의 사용**
#### **포인터**
```cpp
void func(int* p)
{
  *p = 100;
}  
  
int a = 10;
func(&a);
```

#### **참조**
```cpp
void func(int& r)
{  
  r = 100;
}  
  
int a = 10;
func(a);
```
