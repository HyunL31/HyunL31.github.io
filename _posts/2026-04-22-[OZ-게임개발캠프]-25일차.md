## [OZ 게임개발캠프] 25일차 (4/22)

### **1. 유니티 라이프사이클**
- 객체가 생성된 후 Awake(), OnEnable()이 실행된 후 잠시 마침표를 찍은 뒤 Start()가 실행된다.
- 메세지 시스템 기반으로 유니티에서 Update()가 실행되면 게임 오브젝트의 Update()에게 메세지를 전달한다.

<br/>

-----------------

<br/>

### **2. 게임 오브젝트**
- **게임 오브젝트**란 컴포넌트를 담는 그릇이다.
- 게임 오브젝트에 대한 하이어라킹을 잘 해야한다.
	- 보통 사용자 정의 컴포넌트는 최상위 게임 오브젝트에 넣어 자식 오브젝트를 함께 제어한다.
	- 컴포넌트를 스크립트로 가져오기 : `GetComponent<BoxCollider>` 등 (많이 안 쓰는 게 좋다)

<br/>

-----------------

<br/>

### **3. 프리팹**
- 오히려 대형 프로젝트에서는 의도치 않은 수정을 방지할 수 있도록 프리팹의 **Auto Save**를 끈다.
- `Instantiate(프리팹, 위치, 방향, 부모)`으로 동적 생성 (메모리를 할당하는 무거운 작업, 최대한 재사용 해야 한다.)
- `SetParent`로 Root 설정 (UIRoot 등)
- 유니티에서 순회는 비용이 크기 때문에 리스트 등의 자료구조를 사용하는 것이 더 효율적이다.
- 메쉬 등은 프리팹이 참조하는 형태이기에 프리팹의 용량이 늘어나지 않는다.

#### **프리팹 동적 생성 예시**
```csharp
// 실체화 후 부모 설정
var carPrefab = Instantiate(carPrefab, spawnPos, Quaternion.identity);
car.transform.SetParent(carRoot.transform);

// 스페이스 누르면 생성
if (Input.GetKeyDown(KeyCode.Space))
{
	// 실체화와 함께 부모 설정
	Instantiate(carPrefab, spawnPos.position, Quaternion.identity, carRoot.transform);
}
```

### **4. Destroy**
- 런타임에 컴포넌트를 Destory 해서는 안된다.
- `Destroy(this)`를 사용하면 스크립트 컴포넌트가 없어진다.
- Destroy는 즉시 삭제되지 않고 프레임의 모든 로직이 끝난 뒤 정리할 때 삭제된다.
- 즉시 삭제는 `DestroyImmediate`를 사용한다.

### **5. 에셋 (Asset)**
- **에셋**이란 유니티 프로그램 내에서 게임을 만들 때 사용하는 모든 리소스를 의미한다.
- **.jpg** : 압축 손실이 일어난다. (화질, 디테일이 깨진다. 대신 리소스 크기가 작다.)
	- 중요하지 않은 이미지는 jpg가 더 좋을 수 있다.

### **6. 유니티 물리**
#### **좌표계**
- 유니티는 왼손 좌표계를 사용한다. (X, Y, Z 좌표)
- 좌표는 보통 Vector3, Vector2 자료형으로 사용한다. (구조체이므로 값형이다.)
	- C#에서는 new를 사용한다고 힙 메모리에 저장되는 것이 아니다.
	- 참조 전달이 아닌 값 복사가 일어난다.
- Vector3는 RGB 색상에 사용하기도 한다.

#### **쿼터니언 (Quarternion)**
- **쿼터니언** : 오일러 회전의 짐벌락 현상을 방지하기 위해 나온 회전 방법
- 오일러 회전은 X, Y, Z 축이 일정 순서로 순차적으로 회전을 하기 때문에 축이 완전히 겹쳐지는 **짐벌락** 문제가 있었다.
- 쿼터니언은 X, Y, Z, W 축이 한 번에 회전을 하기 때문에 짐벌락이 없다.

#### **Input System (키 입력)**
- **Input.옵션()**메서드로 입력 가능
- 입력은 Update()에서 처리한다.

### **7. 데일리 과제**
키 입력 받아 프리팹 인스턴스하기

```csharp
public class CarSpawner : MonoBehaviour
{
	public GameObject carPrefab;
	public Transform spawnPos;
	public GameObject carRoot;

	private void Update()
	{
		if (Input.GetKeyDown(KeyCode.Space))
		{
			SpawnPrefab();
		}
	}

	private void SpawnPrefab()
	{
		// 실체화와 함께 부모 설정
		Instantiate(carPrefab, spawnPos.position, Quaternion.identity, carRoot.transform);
	}
}
```
