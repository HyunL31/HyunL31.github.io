## 유클리드 호제법

### **1. 유클리드 호제법**
**유클리드 호제법**이란 두 정수의 **최대공약수**를 효율적으로 구할 수 있는 알고리즘이다.

<br/>

#### **공식**
$$GCD(a, b) = GCD(b, a \% b)$$

<br/>

#### **원리**
두 정수 $$a, b (a > b)$$가 있을 때, $$a = b \times q + r$$이다.


이때 $$a$$와 $$b$$의 공약수 집합은 $$b$$와 $$r$$의 공약수 집합과 같으므로 $$GCD(a,b)=GCD(b,r)$$이 성립한다.


따라서 $$a=b, b=r$$로 바꾸는 연산을 반복하면 $$b = 0$$이 되는 순간의 $a$가 최대공약수가 된다.

<br/>

### **2. 최대공약수 (GCD)**

#### **예시**
```cpp
int gcd(int a, int b)
{
	while (b != 0)
	{
		int r = a % b;
		
		a = b;
		b = r;	
	}
	
	return a;
}
```

### **3. 최소공배수 (LCM)**
유클리드 호제법을 사용해 구한 최대공약수를 이용하면 최소공배수도 쉽게 구할 수 있다.
두 정수 a와 b의 곱은 최대공약수와 최소공배수의 곱과 같기 때문이다.

![Desktop View](/assets/img/lcm.jpg){: w="500" h="200" }

<br/>

#### **예시**
```cpp
int lcm(int a, int b)
{
	return (a / gcd(a, b)) * b;
}
```
