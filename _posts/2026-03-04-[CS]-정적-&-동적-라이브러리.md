## 정적 & 동적 라이브러리

### **1. 정적 라이브러리 (Static Library)**
**정적 라이브러리**란 컴파일 시 실행 파일에 코드가 직접 포함되는 라이브러리를 말한다.

<br/>

#### **특징**
- 실행 파일 안에 라이브러리 코드가 같이 들어간다.
- 실행 파일의 크기가 커진다.
- 프로그램 실행 시 외부 라이브러리가 필요하지 않다.
- 라이브러리 업데이트 시 프로그램을 다시 컴파일 해야한다.

<br/>

#### **동작 과정**
1. 프로그램 코드를 작성한다.
2. 프로그램을 라이브러리와 함께 컴파일한다.
3. 실행 파일 안에 라이브러리 코드가 포함된다.

<br/>

-----------------

<br/>

### **2. 동적 라이브러리 (Dynamic Library)**
**동적 라이브러리**란 프로그램을 실행할 때 외부에서 불러오는 라이브러리를 의미한다.

<br/>

#### **특징**
- 실행 시 라이브러리 코드가 포함되지 않는다.
- 실행 파일의 크기가 작다.
- 실행 시 외부 라이브러리를 불러온다.
- 컴파일 필요없이 라이브러리만 업데이트가 가능하다.
- 여러 프로그램이 같은 라이브러리를 공유할 수 있다.

<br/>

#### **동작 과정**
1. 라이브러리 코드 없이 프로그램을 컴파일한다.
2. 실행 시 라이브러리를 로딩한다.

<br/>
